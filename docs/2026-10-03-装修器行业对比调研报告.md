## 一、结论速览（三问回答）

1. **设计是否符合主流？符合，且已达行业第二梯队顶部。** 悦航购装修器采用行业标准的三栏拖拽编辑形态（左组件库→中画布→右属性面板），v3「页面→区块→组件」三层 JSON 数据模型与 Shopify OS2.0 的 sections→blocks 模型同构；10 平台 7 维度评分 **12/14，与店匠并列第二、仅次于 Shopify（13）**，领先微盟/淘宝/京东（11）、有赞/抖店（10）。
2. **功能是否完善？基本完善，有 3 处明确缺口。** 拖拽/排序/复制/删除/图层大纲/撤销重做/属性面板/区块条件/实时预览/草稿自动保存/发布校验/版本管理/回滚/发布审批流/审计日志/模板市场一应俱全。缺：**定时发布**（有赞/微盟/京东/Shopify 均有）、**扫码真机预览**（京东独有公开证据）、**组件市场/第三方生态**（微盟云市场、Shopify App blocks、淘宝服务市场）；另 C 端装修生效靠冷启动拉取，**无运行时推送/即时生效**。
3. **组件是否齐全？齐全（29 个、6 大类），达国内 SaaS 同级水平（微盟官方 30+）。** 覆盖基础/导航广告/商品经营/营销活动/店铺服务/内容；营销组件（优惠券/秒杀/折扣/拼团/倒计时/会员权益）尤其齐全。相对缺：独立营销活动页组件与「签到/积分/分销」类会员运营组件、客服/购物车入口组件、更细的直播电商组件（现仅 1 个 video-live）；「船舶工作台/补给单」为悦航购垂直行业特色组件，属差异化而非缺口。

## 二、悦航购装修器现状（代码取证）

管理端 `page-designer/`（组件注册表 + schema + 画布 + 属性面板 + 图层大纲 + 撤销重做 + 草稿自动保存 + 发布校验/审批 + 版本回滚 + 模板市场），产出 v3「页面→区块→组件」JSON 落库 8 张 `page_design*` 表；C 端 `src/components/diy/` 用同名注册表按 schema 渲染。

### 1. 页面类型（`api/promotion/page-design.ts:4-33`）
`'0'`微页面 / `'1'`商城首页 / `'2'`商详 / `'3'`分类 / `'4'`个人中心；`CREATABLE_PAGE_TYPES=['0','2','3','4']`；首页唯一经 set-home 指派。**无独立营销活动页类型**（拼团/秒杀以组件承载）。

### 2. 组件清单（`registry/component-registry.ts`，共 29 个，均 `supportedTerminals:['admin','uniapp']`，字段级配置见取证报告）

| 分类 | 组件（type / 名称） |
|---|---|
| 基础（6） | custom-html 自定义HTML、gap 空白、notice 公告、rich-text 富文本、search-bar 搜索框、title-text 标题 |
| 导航广告（6） | swiper-banner 轮播、tab-nav 图文导航、category-nav 分类导航、image-ad 图片广告、marketing-entry 营销入口、bottom-nav 底部导航 |
| 商品经营（5） | goods 手选、goods-group 分组、goods-scroll 横滑、goods-ranking 排行、goods-waterfall 瀑布流 |
| 营销活动（7） | coupon-receive 优惠券、coupon-combo 券组合、seckill 秒杀、discount 折扣、limited-activity 拼团、countdown 倒计时、member-benefits 会员权益 |
| 店铺服务（4） | shop-info 店铺信息、service-promise 服务承诺、ship-workbench 船舶工作台、replenish-card 补给单 |
| 内容（1） | video-live 视频/直播 |

每个组件带 `commonStyle`（边距/圆角/背景）、`dataSource`（automatic 规则/manual 手选/current-tenant/ranking）、`empty`/`invalidStrategy`。

### 3. 编辑能力（逐项有据）
拖拽排序（HTML5 `draggable` + `moveComponent/moveSection`）、复制（`duplicateComponent/Section`）、删除（`remove*`）、属性面板（`property-panel.vue` 动态加载 settings）、图层大纲（`page-outline.vue`）、撤销重做（`use-command-history.ts`）、区块/页面设置——**全部具备**。

### 4. 预览/发布链路
实时预览（`phone-canvas` + `preview-token` 独立预览）；草稿 **1.8s 防抖自动存**（revision 乐观锁冲突检测）；发布前前后端双重校验 + 性能预算（组件/图片/请求/KB）；版本管理 + `versions/{vid}/rollback` 回滚；**release→approve 发布审批流**；审计日志。**定时发布未找到**。C 端 `onLoad` 冷启动拉取 + 下拉刷新，数据源级内存 TTL 缓存（默认 60s），**无运行时推送**。

### 5. 模板市场 / 组件市场
模板市场存在：`template-market/index.vue` + `/promotion/pagedesign/templates` CRUD + market 上下架 + `market/list`/`detail`/`download` 一键套用。**组件市场未找到**（组件内置注册表、不可由第三方扩展）。

### 6. 数据模型（`schema/types.ts:67-129`）
`DocumentV3 → page(PageSettings) + sections[] → components[]{id,type,props,version}`，带 `themeRef`（衔接主题色体系）、`terminalOverrides`（分端覆盖）、区块条件（登录态/会员等级/标签/时间段）。DB 表：`page_design`、`page_design_version`、`page_design_release(+_target)`、`page_design_template`、`page_design_theme`、`page_design_audit_log`、`page_design_metric_daily`。

### 7. 多端下发
免登接口 `GET /promotion/app/pagedesign(/type/{t}|/{id}|/preview/{token})`；C 端 `diy/index.vue` 经 `registry.ts` 把 29 个 type 映射到 `Diy*` 组件，与管理端一一对应；契约测试（preview-parity / mobile-renderer）守住两端口径。**无双模式硬编码违规**（grep `VITE_OPEN_BOOT`、`/boot` 零命中）。

## 五、缺口与改进优先级

### 主流标配（已达标，保持即可）
三栏拖拽编辑器 + 实时预览、首页/自定义页/商详/个人中心可装修、29 组件 6 分类、模板一键套用、草稿/版本/回滚。

### P0 · 对齐主流标配的缺口（补上即无短板）
1. **定时发布**：有赞（5 分钟~30 天）[官方](https://help.youzan.com/displaylist/detail_4_4-1-28131)、微盟 [官方](https://help.weimob.com/os/article/8005)、京东（定时列表可取消）[官方]、Shopify 定时/Rollouts [官方 changelog] 均为标配；悦航购 `page_design_release(_target)` 表已具备目标时间字段基础，补齐成本低。
2. **扫码真机预览**：京东独有公开证据（扫码预览）[官方]，悦航购目前仅内置 `phone-canvas` 模拟预览。

### P1 · 对齐行业领先
3. **组件市场 / 第三方生态**：微盟云市场 [官方]、Shopify App blocks [官方]、淘宝服务市场；悦航购组件内置注册表，可先行开放「自定义组件/模板」上传通道。
4. **运行时推送 / 即时生效**：当前 C 端冷启动拉取 + 下拉刷新 + TTL 缓存（60s），活动营销场景需要"发布即生效"，可引入版本号 + 启动校验或 WebSocket 推送。
5. **商详装修深化为独立工作台（SPU 级）**：淘宝/京东/抖店均有独立商详装修 [官方]；悦航购已有商详页面类型（'2'），可在此基础上做 SPU 级模板绑定。

### P2 · 差异化护城河（仅极少数做到）
6. **定时发布 + 到期自动回滚 + A/B**（仅 Shopify Rollouts）——活动"到点上、到点撤"自动化，国内同行全缺。
7. **智能一键装修**（京东按 SKU/分类/PV/人群自动生成 [官方]、抖店标准化装修 [官方]）——悦航购有 `page_design_metric_daily` 埋点表，具备数据驱动基础。
8. **实时数据绑定**（店匠拖拽元素绑商品库存/价格 [官方]）。
9. **自由画布/图层叠加**（店匠悬浮按钮/重叠图 [官方]）。

### 组件级缺口（相对微盟 30+ / 服务市场生态）
- 营销运营类：签到、积分/等级任务、分销裂变组件（现仅 member-benefits 一个会员组件）

# 会员专区 / 低价捡漏 · 配置操作手册

> 适用版本：P0/P1/P2 落地后（2026-11-03）；**会员价活动功能已于 2026-11-03 整体删除**（开发阶段直接清理旧数据、不做迁移），会员价只通过商品专区标签维护。
> **2026-11-04 配置收敛**：专区设置只保留「开关 / 默认折扣率 / 成本兜底倍率 / 出清排序」；「专区标题 / 副标题 / 公告」字段已删除。**专区的展示位置、Tab 标题、公告统一到「页面设计 → 多 Tab 商品流」配置**（专区设置页有「去页面设计配置专区展示」入口）。装修 Tab 的「排序」拆成 **①排序** 与 **②专区选品** 两个维度，旧「折扣力度优先（低价捡漏）」已从装修器移除，历史配置会提示一键迁移。
> 先记住一句话：**商品标签决定「谁进专区」和「会员价规则」，系统托管活动是内部价格载体（运营不可见），装修 Tab 决定「C 端怎么展示」。**
> 三者缺一层，页面就会出现「商品进了专区但没价格」「价格对但列表不是这批商品」等现象。
> 运营日常只需要维护三处：**商品列表「专区打标」/ 商品编辑「专区标签」**、**营销 → 专区设置**（规则与价格）、**页面设计 → 多 Tab 商品流**（展示位置/标题/专区选品）；不再需要创建或维护「会员价活动」。

## 一、三层模型（先理解这个，再看后台）

### 1. 商品标签（商品域）

`goods_spu` / `goods_sku` 上的字段：

| 字段 | 作用 |
|---|---|
| `is_member_item` | 是否进会员专区（SPU 选品主键） |
| `member_discount_rate` | 商品级会员折扣率，如 `0.9000` = 9 折 |
| `member_price_fixed` | 会员固定价（与按率算价取低） |
| `member_price_floor` | 会员价下限（防击穿） |
| `is_clearance_item` | 是否进低价捡漏 |
| `clearance_price` | 出清固定价 |
| `clearance_discount_rate` | 出清折扣率（对原价算） |
| `clearance_expire_time` | 出清截止时间，到期自动退出 |

SKU 级同名字段是「覆盖」：**SKU 有值用 SKU，空则继承 SPU**。

### 2. 系统托管活动（促销域）

标签保存后，后台会自动维护两条系统活动：

| 活动 | `activity_code` | 类型 | 作用 |
|---|---|---|---|
| 会员专区（系统托管） | `SYS_MEMBER_ZONE` | type=10 会员价 | 把会员标签商品算成活动价，供引擎/查价使用 |
| 低价捡漏专区（系统托管） | `SYS_CLEARANCE_ZONE` | type=11 出清价 | 把出清标签商品算成最终出清价（含时间分层） |

- 系统活动优先级固定 `-100`，只承载商品标签算出的价格；
- 系统活动在「船供活动」列表里被隐藏，不能手工编辑/删除；
- 打标、改专区设置、改出清规则、每日兜底 Job 都会重算它；
- **会员价活动功能已整体删除（2026-11-03）**：管理端「船供活动」不再有会员价类型，按 ID 的新建/编辑/发布/暂停/删除接口全部拦截；C 端旧 `activity` 数据源与 `/app/member/activity-goods` 接口已删除；旧手工会员价活动数据已物理清理（开发/测试环境，不迁移）。

### 3. 装修 Tab（展示层）

装修器的 `goods-tabs` 组件数据源只有「按分类/排序自动」与「手选商品」两项；2026-11-04 起「自动」模式在 UI 上拆成 **①排序** 与 **②专区选品** 两个下拉（详见 §四）。

| 配置 | 实际请求 | 用途 |
|---|---|---|
| 自动 + 专区选品 `低价捡漏（出清标签商品）`（底层 `sort=clearance`） | `/app/goodsspu/page?clearanceItem=true&sort=clearance` | **低价捡漏**：只看出清标签，价格取出清最终价（含时间分层） |
| 自动 + 专区选品 `会员专区（会员标签商品）`（底层 `sort=member_price`） | `/app/goodsspu/page?memberItem=true&sort=member_price` | **会员专区**：只看会员标签，按售价升序稳定分页 |
| 自动 + 排序（销量/新品/价格，仅非专区 Tab） | `/app/goodsspu/page?sort=...` | 普通商品 Tab 的常规排序 |
| 手选商品 | `/app/goodsspu/list/{ids}` | 运营手选固定商品；**不套用专区标签与专区开关** |
| 自动 + 旧 `sort=bargain`（历史配置） | `/app/goodsspu/page?bargainRate=1.3` | **旧 F1 自动检漏**：按折扣率扫全店；2026-11-04 已从装修器移除选项，仅兼容历史文档并提示迁移 |

代码锚点：
- 管理端 Tab 编辑器：`aryn-mall-ui/.../views/promotion/page-design/components/extension/extension-settings.vue`（类型 `extension/types.ts`）；专区设置页：`views/promotion/zone-setting/index.vue`
- 前端参数映射：`aryn-mall-uniapp/src/components/diy/retail-query.ts`
- 商品列表分支/专区开关：`AppGoodsSpuController#page`
- 出清专区最终价与排序：`GoodsZoneTagService#clearancePage`
- 会员专区货盘：`AppGoodsSpuController#page`（`memberItem=true&sort=member_price`）
- 系统活动同步：`MallZoneActivitySyncServiceImpl`
- 价格链：`OrderPriceComputeService`

## 三、后台操作步骤

### 3.1 给商品打标（会员/出清）

入口：管理端 → 商品 → 商品列表。

**批量操作（商品列表弹窗 v2，2026-11-04 重做）**
1. 勾选商品 → 点「批量设置规则」（**加入/更新**）或「移出专区」（**破坏性操作单独入口**）；
2. 弹窗打开即**预检**：展示所选商品在各专区的现状（已在 N 件 / 未加入 N 件 / 规则将变化 / 无变化 / 有 SKU 精调 / 异常），并汇总本次影响；
3. 「批量设置规则」弹窗只提供 **加入/更新规则** 与 **不修改**；「移出专区」弹窗只提供 **移出专区** 与 **不修改**（默认移出）。选择加入/更新后填写规则（不填=沿用旧规则或专区默认折扣）；
4. 底部确认按钮显示实际动作数量（如「确认：加入 2 件」「确认移出 10 件」）；全部无变化时不可提交；
5. 提交后展示**结果面板**：成功/无变化/失败明细 + 价格同步状态（同步失败会明确提示，不再显示「已同步」）；支持复制失败清单、重试失败项、查看本次商品、撤销本批次。
- 移出专区会清空 SPU 规则与全部 SKU 精调，需二次确认；
- 单次最多 200 件，超过时页面自动分片提交并显示进度。

**单商品精调**
商品编辑 → 顶部「专区标签」页签（2026-11-04 起独立保存，不再依赖商品主表单）：
- SPU 级：会员是否加入/折扣率/固定价/下限；出清是否加入/出清价/折扣率/截止时间；支持显式清空规则（标签保留）；
- SKU 级：逐行选择「继承 / 覆盖」，覆盖可单独配会员/出清规则，保存时精确覆盖（清空字段=恢复继承）；
- 页面展示缺规则/倒挂/到期/下架等告警。

**校验规则**
- 会员/出清折扣率必须在 `(0, 1)`；
- 固定价/下限必须 > 0；
- 出清必须至少有固定价或折扣率；按折扣率算价要求商品有原价；
- 出清截止时间不能主动改成过去时间；
- 算出的价格必须低于当前售价，否则不生效（倒挂保护）。

价格计算规则：

```text
会员价 = min(售价 × min(商品折扣率, 等级折扣率), 会员固定价)
        结果不低于会员价下限，且不高于售价
出清价 = 固定价，或 原价 × 出清折扣率
        命中时间分层时再乘最深一档折扣（不连乘）
```

**会员价下限的优先级**（从高到低）：

1. 商品/SKU 显式填写的 `member_price_floor`；
2. 专区设置里的「成本兜底倍率」× 成本价（例如 1.05 = 成本上浮 5%）；
3. 默认 0.01。

批量打标不提供「会员价下限」输入（后端也忽略该字段），系统按每个商品的成本自动兜底；只有个别商品需要特殊底价时，再在单商品精调里填写 `member_price_floor`。

> 成本兜底只作用于「会员价」，不会改变商品售价；若算出的会员价仍高于售价，该商品不产生会员价（倒挂保护）。
> 下单时等级折扣取优同样受该下限约束：等级折扣价低于「成本 × 倍率」时回退会员价/下限，不会击穿成本。
> 出清价属于清仓让利，不套用会员成本兜底；优惠券/积分是否允许击穿成本由现有最低实付兜底单独控制。

**按专区筛选商品（复核打标结果）**

商品列表查询区新增「专区」下拉，可选：**会员专区 / 低价捡漏 / 未加入专区**（空=全部）。

- 口径与列表「专区」列一致：只看商品标签，**不看到期时间**——已到期的出清商品仍会出现在「低价捡漏」结果里，方便续期或取消标签；
- 想复核「这批商品到底打没打标」「还有多少商品没进专区」时用这个筛选，不用再翻页找；
- 该条件位于查询区默认展开的前三个条件内（商品名称 / 商品类目 / 专区）。

### 3.1.1 专区商品管理页（推荐日常入口）

入口：管理端 → 营销 → 专区商品管理（`/promotion/zone-goods`）。

- 顶部：会员专区 / 低价捡漏 tabs，专区开关、默认折扣率、系统活动状态、已同步商品数、最近同步时间/结果（失败可点「重试同步」）；
- 筛选：商品名称 / 类目 / 品牌 / 状态；支持跨页选择与「全选筛选结果」；
- 表格：当前规则摘要、SKU 精调数、生效状态（生效中/未配规则/倒挂不生效/已到期/已下架）、生效价；
- **添加商品**：候选列表默认只看「未加入本专区」商品，可跨页选择/全选，选完进入预检弹窗设置规则后加入；
- **批量设置规则 / 批量移出专区**：复用预检弹窗；移出前展示影响范围（规则清空数、SKU 精调数）；
- **行内调整规则**：抽屉内直接编辑 SPU + SKU 规则（同单商品精调能力）；
- 「换一批」标准流程：筛选本专区 → 全选筛选结果 → 批量移出 → 筛选未加入 → 全选新批次 → 加入/更新规则（两步批量，无需逐页勾选）。

### 3.1.2 批次记录与撤销

入口：专区商品管理页 → 「批次记录」。

- 按时间倒序列出批量操作：操作人、时间、动作、商品数、成功/无变化/失败数、同步状态、撤销状态；
- 可查看批次明细（逐商品变更前后快照），对未撤销批次执行「撤销本批次」；
- 撤销只回滚本批次实际变更的字段；若批次之后有人工修改（当前值与批次 after 不一致），该项会跳过并列入冲突明细，不会覆盖后续人工调整；
- 撤销后原批次标记为「已撤销」，不能重复撤销。

### 3.2 专区设置

入口：管理端 → 营销 → 专区设置（`promotion/zone-setting`）。

> 2026-11-04 起本页**只配置规则与价格**：专区在 C 端的展示位置、Tab 标题、公告统一到「页面设计 → 多 Tab 商品流」配置（页头有「去页面设计配置专区展示 →」入口）。本页原有的「专区标题 / 副标题 / 公告」字段已删除。

| 配置 | 作用 |
|---|---|
| 会员专区开关 | **C 端会员专区货盘与会员价的总开关**；关闭后会员价接口/会员标签列表都不再出价/出货盘，商品标签保留，重开自动恢复 |
| 低价捡漏开关 | **C 端出清货盘与出清价的总开关**；关闭后出清列表与查价返回空，商品标签保留 |
| 默认折扣率 | 商品没配自己折扣时兜底（会员/出清各一份）；会员仍与等级折扣率取优、不叠加 |
| 成本兜底倍率 | 会员专用：商品未显式配下限时，会员价下限 = 成本价 × 倍率（建议 1.05）；空=不启用 |
| 专区排序（出清排序） | 出清支持「出清价从低到高 / 折扣从高到低」；**作用于 C 端所有出清列表（含装修 Tab），装修 Tab 里的排序对出清专区不生效**；会员专区按售价升序稳定分页 |
| 专区展示位置/标题/公告 | **不在本页配置**：去「页面设计 → 多 Tab 商品流」配 Tab 位置与标题；会员横幅由该 Tab 的「会员权益条」控制 |

保存后会立即重算系统活动。

> **2026-11-04 视觉改版（页面不变、交互更明确）**：两个专区改为并排卡片，卡片头显示「已开启/已关闭」状态与开关，卡片脚显示 **C 端价格同步状态 + 生效 SKU 数 + 保存按钮**。
> - 右侧 chip 是当前口径的即时翻译：「≈ 9 折」「成本上浮 5%」「仅用等级折扣 / 不参与出清 / 未启用」；
> - 改动后卡片脚出现「未保存 / 撤销」，保存按钮才可点；**未改动时保存是禁用态**，避免误以为点过就生效；
> - 保存后若同步失败，卡片脚会变「C 端价格同步失败」并出现 **「重试同步」**（无需改任何字段即可重试，触发按租户全量重算，同一租户 30 秒内只算一次）；
> - 关闭专区时卡身会出现关闭影响提示；页面底部不再常驻长说明。

### 3.3 出清时间分层规则

入口：管理端 → 营销 → 出清折扣规则（`promotion/clearance-rule`）。

- 输入「距到期 ≤ N 小时」+「再打折率」；
- 同一商品命中多档时只应用**最深一档**（最小折扣率），不连乘；
- 例：出清价 9.00，规则「≤24h 再 6 折」→ 结算/展示 5.40；
- 保存/修改/删除后立即重算系统活动。

### 3.4 历史手工会员价活动（功能已删除）

> 会员价活动功能已于 2026-11-03 整体删除：管理端无新建/编辑/迁移入口，`/promotion/zone/migration/*` 接口与相关 Job 已删除，旧手工会员价活动数据由双向增量脚本物理清理（boot `194member_price_activity_purge_incremental.sql` / cloud `199member_price_activity_purge_incremental.sql`，开发/测试环境直接删除、不迁移）。
> 若某个环境仍需保留旧活动价格，请勿执行该清理脚本；本功能已不再提供迁移工具。

## 四、装修 Tab 怎么配

> 2026-11-04 起，多 Tab 商品流编辑器的「自动」模式拆成两个维度：
> - **① 排序**：销量优先 / 新品优先 / 价格从低到高——**仅在「专区选品 = 不参与专区」时显示**，对专区 Tab 不生效；
> - **② 专区选品**：**不参与专区（普通商品）** / **会员专区（会员标签商品）** / **低价捡漏（出清标签商品）**——决定这个 Tab 按哪个商品标签圈品。
>
> 旧「折扣力度优先（低价捡漏）」已从可选列表移除；历史 Tab 若是它，编辑时会显示警告与 **「改为「低价捡漏（按标签）」」** 一键迁移。

### 4.1 低价捡漏（推荐新配置）

1. 首页装修 → 选中「低价捡漏」Tab；
2. 数据源选择 `按分类/排序自动`；
3. 在 **「专区选品」** 选 **`低价捡漏（出清标签商品）`**（选中后该 Tab 按出清标签圈品）；
4. 「排序」对出清专区不生效——出清顺序以「营销 → 专区设置 → 低价捡漏专区 → 专区排序」为准；
5. 不再需要「折扣率阈值」；`显示数量` 按需设置（如 10）；
6. 保存草稿 → 发布。

发布后该 Tab 只展示「打了出清标签且未到期」的商品，价格取系统活动最终价（含时间分层），倒挂/过期自动剔除。

> 旧配置 `折扣力度优先（低价捡漏）`：该选项**已从装修器移除（2026-11-04）**，C 端与后端仍兼容历史文档（不会报错、可正常发布）。历史 Tab 编辑时会在「专区选品」显示禁用的「折扣力度优先（旧版，已停用）」+ 黄色警告（标题「旧版「折扣力度优先」已停用」）与 **「改为「低价捡漏（按标签）」」** 按钮，点击即切换为「按分类/排序自动 + 专区选品：低价捡漏（出清标签商品）」。它扫全店折扣率、不是标签选品，看到不该出现的商品时优先检查这里。

### 4.2 会员专区（唯一推荐配置）

1. 选中「会员专区」Tab；
2. 数据源选择 `按分类/排序自动`（数据源只有「按分类/排序自动 / 手选商品」两项；会员价活动数据源已随功能删除）；
3. 在 **「专区选品」** 选 **`会员专区（会员标签商品）`**；
4. 「排序」对会员专区不生效（会员专区按售价升序稳定分页），该下拉不显示；
5. 「会员权益条」按需开启：**它只控制 Tab 顶部横幅**，不控制会员价；建议**仅会员专区 Tab 开启**；
6. 「每页加载数量」按需设置（如 10，C 端滚动自动加载下一批）；
7. 保存 → 发布。

这样会员专区 = 「打了会员标签的在售商品」，按售价升序、分页加载，不再受活动货盘和单页条数截断影响。

**口径修正（2026-11-04）**：旧手册写「会员权益条是卡片会员价的总开关」是错误表述。实际口径：
- **会员价的总开关是「营销 → 专区设置 → 会员专区开关」**；关闭后 C 端不再出货盘、不再出会员价；
- **会员权益条只渲染 Tab 顶部横幅**（会员/游客三态文案）；会员价/捡漏价在所有 Tab 的商品卡都会由共享补价层展示（跨页面价格一致性，2026-11-03），与权益条无关；
- 因此「权益条关闭 → 会员价也消失」的说法不成立；要隐藏卡片会员价请关闭专区设置开关。

**手选商品模式提示**：若该 Tab 数据源选「手选商品」，该 Tab **不套用专区标签与专区开关**（走通用 `list/{ids}`），专区开关关闭也照常展示手选商品、价格也不走专区价。需要「按标签圈品 + 受专区开关控制」时，请务必用「按分类/排序自动 + 专区选品」。

### 4.3 会员价未登录/未达标时

- 未登录：卡片显示「会员专享 ¥x」引导，主价保持原价；
- 登录但等级不达标：同样只显示引导；
- 达标：主价切会员价，划线价为活动前售价；
- 会员价与等级折扣率取优，不叠加。

## 五、发布后自检清单

1. **专区设置开关**是否打开（会员专区 / 低价捡漏各自的开关，才是 C 端货盘与价格的总开关）；
2. 商品是否打了对应标签，且 `status` 上架、SKU `status='0'`；
3. 低价捡漏 Tab：数据源为 `按分类/排序自动`、**专区选品 = `低价捡漏（出清标签商品）`**，且没有残留旧「折扣力度优先（低价捡漏）」——若有，先按提示一键迁移；
4. 会员专区 Tab：数据源为 `按分类/排序自动`、**专区选品 = `会员专区（会员标签商品）`**；「会员权益条」只在需要横幅的 Tab 开启（**它不是会员价开关**）；
5. 专区展示位置/标题/公告是否在装修器里配好（专区设置页已不再有这些字段）；
6. 发布后 C 端下拉刷新（小程序可清缓存）；
7. 接口核对：
   - `/app/goodsspu/page?clearanceItem=true&sort=clearance` 返回的 `total` 是否等于打标数；
   - `/app/clearance/prices?skuIds=...` 是否返回最终价（含分层）；
   - `/app/member/prices?spuIds=...` 是否覆盖全部会员标签商品；
   - `/app/goodsspu/page?memberItem=true&sort=member_price` 的 `total` 是否等于会员标签商品数；
8. 价格与结算一致性：确认页/提交订单应取同一系统活动最终价。

## 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 低价捡漏出现大量非打标商品 | Tab 还是旧「折扣力度优先（低价捡漏）」（`sort=bargain`，扫全店折扣率） | 编辑该 Tab，按提示点「改为「低价捡漏（按标签）」」；或直接把专区选品改成 `低价捡漏（出清标签商品）`，发布 |
| 专区设置里找不到「标题 / 副标题 / 公告」 | 2026-11-04 已收敛：这三个字段从专区设置删除（C 端无消费方） | 去「页面设计 → 多 Tab 商品流」配置 Tab 标题/位置；会员横幅用该 Tab 的「会员权益条」 |
| 会员权益条关闭后会员价还在 / 会员专区卡片没会员价是不是权益条导致的 | 权益条**只控制 Tab 顶部横幅**，不控制会员价（2026-11-04 口径修正） | 会员价总开关是「营销 → 专区设置 → 会员专区开关」；只想隐藏横幅才关权益条 |
| 改了装修 Tab 的排序，出清顺序没变 | 出清排序以专区设置 `sortMode` 为准，装修 Tab 的排序对出清专区不生效 | 去「营销 → 专区设置 → 低价捡漏专区 → 专区排序」调整 |
| 手选商品 Tab 里商品在专区关闭后仍显示 | 手选商品走通用 `list/{ids}`，**不套用专区标签与专区开关**（已知限制） | 需要随专区开关联动时，改用「按分类/排序自动 + 专区选品」 |
| 会员专区有的商品没会员价 | ① 专区设置的会员专区开关关闭；② 未登录只显示引导；③ 商品未打会员标签，或打了标签但没配折扣率/固定价（也不会套用专区默认折扣时）；④ 价格倒挂或低于成本兜底，按规则不生效 | 打开专区开关；登录查看；补会员规则；价格保护属预期 |
| 会员专区出现非打标商品 | 该 Tab 的数据源/专区选品异常（可能是旧文档） | 重新保存/发布装修，数据源选「按分类/排序自动」+ 专区选品「会员专区（会员标签商品）」 |
| 活动页找不到会员价类型 | 会员价活动功能已整体删除（2026-11-03） | 用商品列表「专区打标」/商品编辑「专区标签」维护会员价 |
| 列表价与确认页不一致 | 出清列表未走最终价，或缓存未刷新 | 确认 Tab 专区选品为 `低价捡漏（出清标签商品）`；发布后清 `page_design_cache`/下拉刷新 |
| 系统活动在活动列表找不到 | 系统活动被隐藏且禁止编辑 | 正常；通过商品标签/专区设置维护 |
| 改了商品标签但页面没变 | 页面缓存/未刷新 | 重新发布装修或清缓存；确认同步日志 |
| 出清到期仍在列表 | 缓存或商品 SPU/SKU 到期时间未更新 | 检查 `clearance_expire_time`；每日 Job/保存后同步 |

## 七、让利报表（P2）

入口：管理端 → 经营分析（`dashboard/analytics`）→「专区让利」。

口径：
- 只统计已支付订单；
- 让利 = Σ（活动前单价 − 成交单价）× 数量 + 会员折扣金额；
- 商品实付 = `payment_price − freight_price`；
- 不含优惠券、积分与退款冲减；
- 数据来自下单时写入的 `order_item.zone_source / activity_base_price`。

## 九、一句话操作结论

- **想让低价捡漏只卖你选的那几个**：装修 Tab 数据源用「按分类/排序自动」+ **专区选品「低价捡漏（出清标签商品）」**。
- **想让会员专区只卖你选的那几个**：装修 Tab 数据源用「按分类/排序自动」+ **专区选品「会员专区（会员标签商品）」**；会员权益条只控制横幅，需要横幅再开。
- **想改专区在 C 端的位置/标题/公告**：去「页面设计 → 多 Tab 商品流」，专区设置页不再有这些字段。
- **想临时加/减商品或改价**：商品列表「专区打标」或商品编辑「专区标签」页签；不要直接改系统活动；**会员价活动功能已整体删除，活动页不再有会员价类型**。
- **会员价唯一维护入口**：商品标签（谁进专区、折扣率/固定价/下限）+ 专区设置（开关、默认折扣、成本兜底）；出清排序也只在专区设置里改。

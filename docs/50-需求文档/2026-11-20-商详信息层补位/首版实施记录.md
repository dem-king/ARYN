# 商详信息层补位首版

## 已实现

- 小程序在评价前展示商品参数。品牌、类目和真实 SKU 规格有值才显示，包装换算仅展示明确的件数换算，普通商品默认的 1 件起订和递增隐藏。多规格行打开现有规格弹层。
- 船供场景且船舶与靠港上下文齐全时，原配送信息移到「当前靠港安排」卡。顶部「详情」标签跳到图文详情。商详参数变化、装修加载和评价加载后更新导航位置。
- 现有商品详情查询通过左连接返回同租户品牌、类目名称。管理端装修画布在对应位置显示原生参数卡的示意。
- 两种模式的 `1013goods_detail_sample_incremental.sql` 只回填银鹭花生牛奶 450ml 的缺失品牌和 SKU 规格文本。450 mL 来自实际商品标题。箱规需实物资料确认，专票及理赔文案需有租户政策依据。 [Boot 增量](../../../aryn-mall-java/db/boot/1013goods_detail_sample_incremental.sql) · [Cloud 增量](../../../aryn-mall-java/db/cloud/1013goods_detail_sample_incremental.sql)

- UniApp 类型检查通过，相关定向单测通过 116 项。Boot 和 Cloud 两种模式的微信小程序构建均通过。管理端画布契约通过 6 项。商品详情的 Boot 和 Cloud 路径分别核对为 `/boot/app/goodsspu/{id}` 和 `/product/app/goodsspu/{id}`。

## 2026-11-21 后续实施

- 移除评价前重复的「商品详情」入口和管理端预览占位。顶部标签继续使用原图文锚点。
- 管理端商品编辑新增「商品参数」，支持最多 12 项、标签去重、删除和回显。旧客户端省略参数字段时保留原数据，提交空数组时清空。小程序默认展示 8 行，支持展开。食品字段由运营根据包装资料录入。
- 阶梯提示根据所选 SKU 的起订量、步长和库存计算，下一档低于当前价且数量变化不会触发协议价时才提示。买赠和满量满额按各自的门槛展示，是否享受优惠以结算为准。
- 新增商详只读优惠接口。游客看公开规则，船舶、靠港、港口活动通过商城会话、租户与在船身份校验。需要首单资格或明确采购主体的规则继续在结算判定。
- 1 至 2 条评价直接展示评价，3 条起汇总真实用户评价中出现最多的六个标签。开票和理赔需要租户政策依据，「大家问」仍需独立的内容来源。
- 已核对 Boot 和 Cloud 路径，隔离 MySQL 验证了参数列初始化、重复执行、保留已录入数据，以及 Cloud 网关配置内容和校验值。现用环境部署及微信真机验收待执行。 [Boot 参数增量](../../../aryn-mall-java/db/boot/1014goods_spu_params_incremental.sql) · [Cloud 参数增量](../../../aryn-mall-java/db/cloud/1014goods_spu_params_incremental.sql) · [Cloud 网关增量](../../../aryn-mall-java/db/cloud/1015goods_hints_gateway_whitelist.sql)
- Boot 编译及 55 项后端定向测试通过。管理端类型检查及 45 项定向测试通过。小程序类型检查、1,986 项单测和 Boot、Cloud 两种模式的微信小程序构建通过。共享 SKU 弹层的既有 ESLint 错误数量为 66，改动前后相同。

## 2026-11-22 商详满减文案

- 商详将「海员整船满减·4%档」显示为「整船采购满减」。固定金额满减以各档门槛和减免金额为准，展示时省略活动名末尾的百分比档位后缀。
- 满减说明明确门槛仅按符合活动条件的商品计算，满足多档时取最高减免。赠礼单独说明金额口径。
- UniApp 类型检查和 2,027 项单测通过。Boot 微信小程序和 Cloud H5 构建通过，商详优惠路径分别为 `/boot/app/goods-hints/{id}` 和 `/promotion/app/goods-hints/{id}`。

## 一、P0 交付内容

### 1. 独立窗口形态

- 新增静态路由 `/message/service-window`（`noBasicLayout`、`sessionInvalidModal`、`hideInMenu`、`hideInTab`），不依赖后端菜单，boot/cloud 双模式一致。
- 新增独立窗口壳 `views/message/service-window.vue`：全屏 100vh、顶栏（品牌/接待状态/未读会话数/收回主窗口）、窗口标题未读数、锁屏遮罩、重复窗口自关、「收回」无法自关时降级为页面内工作台。
- `views/message/service/index.vue` 改为嵌入薄壳；工作台主体抽到 `service-desk.vue`，两壳共用，通过 `mode: 'embedded' | 'window'` 切换高度/圆角/入口。
- `window.open(url, 'aryn-service-desk', features)` 命名窗口 + 保留 opener 句柄：去重、聚焦、关闭、主窗口刷新后按窗口名重取句柄；弹窗被拦截时给出可点链接降级。

### 2. 跨窗口协同（`store/service-window.ts`）

- 通道：`BroadcastChannel('aryn-service-desk')` 为主，`localStorage` storage 事件兜底；独立窗口存活用 2s 租约 + 8s 超时 + 窗口句柄三重判定（规避隐藏窗口定时器节流误判）。
- **提醒单宿**：独立窗口打开即做提醒宿主，主窗口 `messageStore` 跳过声音/语音/桌面通知（未读计数/列表照常刷新）；独立窗口关闭 8s 内主窗口自动接管。
- 铃铛跨窗定位、已读/领取/转交/关闭跨窗收敛、登出/锁屏/租户切换联动。
- 主窗口刷新后仍可通过租约 + 命名窗口恢复「聚焦/收回」。

### 3. 会话失效阻断点

- `RouteMeta.sessionInvalidModal` + `isBasicLayoutContext()` 白名单；独立窗口 401 走页内弹窗原地重登，不再降级登出清持久化 token（会连主窗口一起登出）。

### 4. S0 硬伤修复

草稿按会话隔离、历史消息上翻（`beforeSeq` + 滚动锚点）、列表失败重试态、滚动跟随暂停 +「N 条新消息 ↓」、转交/强制分配可搜索选人（无权限降级手输）、独立窗口启动 WS、双窗提醒去重、铃铛跨窗定位。

### 5. 深色令牌层

`desk-tokens.css`：`:root` 工作台色板、作用域 `--el-*` 映射、`html.desk-theme` 覆盖 teleport 弹层；离开工作台自动移除，不污染其它页面。

## 二、P1 交付内容（2026-11-06）

### 1. 逻辑拆分（composables）

| 文件 | 职责 |
|---|---|
| `use-desk-conversations.ts` | 页签、cursor 分页、本地搜索、请求代际 |
| `use-desk-messages.ts` | 打开会话、时间线渲染项、上翻历史、滚动跟随、发送/重发、已读、草稿持久化与跨窗同步 |
| `use-desk-presence.ts` | 坐席门禁、状态提示、容量、状态切换、坐席保存 |
| `use-desk-shortcuts.ts` | 快捷键纯函数匹配 + 挂载/卸载 |
| `use-desk-quick-replies.ts` | 本地常用语解析/校验/增删改 + localStorage 按坐席隔离 |

`service-desk.vue` 保留模板编排；消息/列表/ presenza 逻辑不再堆在单文件里。

### 2. 上下文面板（右栏）

- 重写 `conversation-info-panel.vue`：会话状态卡（状态/队列/负责客服/关键时间/复制会话 ID）、卡片消息索引（商品/订单/退款/通知/图片，去重取最新）、上下文 contextPayload 折叠展示。
- 新增 `context-utils.ts`：`extractConversationCards()` 纯函数（坏 payload 兜底、同业务卡片去重、按时间倒序、最多 20 条）+ 单测。

### 3. 消息时间线

- 跨天日期分隔；打开会话时按打开前的已读游标插入「以下为新消息」边界；
- 同一发送人 5 分钟内连续消息聚合（组首显示发送者、间距收紧）；
- 文本消息 hover「复制」；不再展示内部 `#seqNo`。

### 4. 会话列表

- 搜索（昵称/会员 ID/摘要）、页签计数、相对时间、会员头像、待领取/主管视图队列与负责人标签；
- 首屏骨架屏；空态/加载失败态/无匹配态区分；页签 `role=tablist/tab` + `aria-selected`，会话行 `aria-current`。

### 5. 键盘效率

- `/` 或 Alt+K 聚焦搜索；Alt+↑/↓ 上/下会话；Alt+N 下一个未读；Alt+Shift+P 弹出独立窗口；`?` 帮助；Esc 关闭弹层/清空搜索；输入态只放行 Esc；不占用 Ctrl/⌘+K。
- 新增 `shortcut-sheet.vue` 帮助浮层。

### 6. 本地快捷回复

- 新增 `quick-reply-dialog.vue`：搜索、插入、删除确认、新增常用语（校验空值/长度）；
- `use-desk-quick-replies.ts`：按 staffId 存 localStorage、内置 5 条默认、50 条上限、读写异常静默降级；
- 输入区「快捷回复」入口，插入到草稿末尾（保留已输入内容）。

### 7. 响应式布局（容器宽度驱动）

- 用 `useElementSize` 监听工作台容器（不是视口）：
  - ≥1440 三栏（列表 + 会话 + 上下文常驻）；
  - ≥1100 两栏（上下文收进抽屉，头部「会话信息」入口）；
  - <1100 单栏（会话内「返回列表」）。
- 上下文抽屉复用同一面板，`dismissible` 时显示收起按钮。

### 8. 提示合并与连接状态

- 主区「会话状态横幅 + 实时连接告警」合并为单条 `deskNotice`，不再多条横幅堆叠；
- 左栏保留 presence 专属提示（与坐席状态同位置）。

### 9. 桌面通知点击 / 跨窗草稿

- 提醒 payload 增加 `conversationId`；桌面通知点击：独立窗口存活 → 定位到独立窗口；否则派发 `aryn:open-conversation` 事件，由主框架路由到工作台、页面消费待定位会话。
- 草稿通过 `storage` 事件跨窗口同步（仅同步当前打开的会话）。

### 10. 无障碍与可读性

- 深色 token 次要文字对比度上调（`--desk-dim` 4.05→6.0、`--desk-faint` 3.42→5.5）；
- 全局 `:focus-visible` 描边、`prefers-reduced-motion` 降级、状态不单靠颜色、aria 标签补齐到页签与列表行。

### 11. 主窗口嵌入工作台占位态（2026-11-06 追加）

- 独立窗口打开后，主窗口 `/message/service` 不再渲染完整工作台，改为占位卡：显示接待状态、未读会话数，只保留「聚焦独立窗口」「收回工作台」两个入口；
- 主窗口其它业务页面保持可用（不锁整窗）——原始目标就是「独立窗口接待 + 主窗口处理其它工作」；
- 独立窗口关闭/收回后，占位卡随 `deskAlive` 变为 false 自动恢复为完整工作台；聚焦失败时立即重新判定存活，避免干等 8s 租约；
- 避免同一坐席双窗口同时操作同一批会话（双份草稿/未读入口/重复操作按钮）。
- 产品口径已确认（2026-11-06）：**只禁用嵌入工作台页，不锁主窗口其它页面**；「整窗锁定」不做默认行为。

### 12. 组件拆分进度（2026-11-06 续作已完成）

- P1 阶段已拆出：`conversation-info-panel.vue`（上下文面板）、`transfer-dialog.vue`、`quick-reply-dialog.vue`、`shortcut-sheet.vue`；

# 50 需求文档

重大需求在本目录下建立 `YYYY-MM-DD-需求名/`，用于实现前评审和实现后复盘。推荐结构：

```text
YYYY-MM-DD-需求名/
├── README.md
├── 01-需求来源与总览.md
├── 02-业务流程与状态.md
├── 03-接口与数据变更.md
├── 04-前端交互与兼容.md
├── 实施拆分与验收清单.md
└── 当前代码与测试环境核对结论.md
```

每个需求包至少写明：原始请求、目标/非目标、影响端、权限与租户、接口和表、兼容策略、验收命令、实际结果与剩余风险。

小型低风险改动可以只在 [需求记录](../90-记录归档/需求记录.md) 登记，但涉及跨端、数据库、认证、租户、支付或状态机时必须建需求包。

当前执行计划保存在 [`docs/exec-plans/active`](../exec-plans/active/2026-07-16-project-onboarding.md)。

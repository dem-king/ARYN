# 分类页与个人中心页精品风格装修（2026-09-30）

> 需求：装修功能已支持分类页（pageType=3）、个人中心页（pageType=4）等页面的嵌入式装修，
> 按主流精品商城的页面套路为这些页面铺一版初始装修并发布，让 C 端开箱即得精品观感。

## 一、风格调研结论

本机网络受限（WebSearch/WebFetch 不可用），调研依据为既有产品形态知识与项目内参照
（93 号脚本明确以「美团自营 / 小象超市」为标杆，库里另有「小象超市风格首页」装修）。
主流精品电商（小象超市 / 京东居家 / 天猫甄选）在分类页与个人中心页上的共同套路：

1. **楼层化**：页面由「banner → 主题楼层 → 商品流」的楼层序列组成，每层只讲一件事。
2. **卡片化栅格**：统一 8–10px 外边距、12px 圆角、白卡浮于浅灰底（#F7F8FA / #F8F8F8）。
3. **数据驱动优先**：楼层内容跟商品/活动数据走；没有运营数据的楼层宁可不上，
   组件空态自动隐藏（`emptyStrategy=hide`），绝不出现「暂无商品」残页。
4. **克制**：分类页右栏是窄栏（287px），楼层以「氛围 banner + 榜单 + 横滑」三段为上限；
   个人中心页静态卡片已很密，装修只补「会员活动位 + 服务公告」。

结合环境数据取舍：本地租户**优惠券 0 张、秒杀/拼团/折扣活动 0 场**，故活动类组件全部不上；
商品楼层数据源走 `ranking` / `rule`（394 个在售商品充足）。

## 二、设计方案

### 分类页（pageType=3，内嵌右栏商品流顶部，栏宽约 287px、白底）

| 楼层 | 组件 | 关键取值 |
|------|------|----------|
| 活动轮播 | swiper-banner | 高 120px（263px 宽 ÷ 2.19 图比，零变形）、圆角 12、5s 间隔、3 张首页品牌图（品质好物/海鲜盛宴/时令鲜蔬） |
| 热销榜 | goods-ranking | 「热销榜」Top5、排名号、划线原价、数据源 ranking/sales |
| 掌柜推荐 | goods-scroll | 「掌柜推荐 · 热卖好货」、手动横滑 perView=3、8 个、划线原价、数据源 rule/sales |

后两个楼层收进 `#f7f8fa` 圆角卡片（marginX 8 / radius 12），与右栏白底形成层次；
组件 `commonStyle` 背景同步填 `#f7f8fa`（避免 useDiyStyle 渐变兜底出现白卡叠灰卡）。

### 个人中心页（pageType=4，嵌在资产条与「我的订单」之间，页面底色 #F8F8F8）

| 楼层 | 组件 | 关键取值 |
|------|------|----------|
| 会员活动 | image-ad（单图堆叠） | 高 162px（355px 宽 ÷ 2.19，零变形）、圆角 12、新人专享图、左右边距 10px |
| 服务公告 | notice | 白卡（marginX 10 / radius 12 / paddingY 6）、「公告」红色前缀 + `精选全球好物 · 每日新鲜直达` |

边距/圆角刻意与宿主 `uc-card`（20rpx=10px 边距、24rpx=12px 圆角）对齐；
公告条跑马灯是 wd-notice-bar 默认行为（`scrollable` 默认 true）。

### 字段口径（手写装修 JSON 的关键）

props **透传不迁移**，必须按 C 端渲染组件实际读取的字段写：
`notice` 用 `contentList/color/titleType/titleText/...`（registry 的 `createDefaultProps`
里 `content/bgColor` 是 v1 遗留死字段）；`image-ad` 用 `type('1'堆叠)/height/imgRadius/interval(秒)`，
而 `swiper-banner` 的 `interval` 是毫秒且组件自带 12px 横向 margin（忽略 commonStyle）。
长度单位一律 px（Schema v3 口径）。

## 五、遗留与建议

1. **商详页（pageType=2）未装修**：装修嵌入点在商品信息与评价之间，而页面底部已有静态
   「你可能还会喜欢」瀑布流，再放推荐楼层会重复；如要装修建议先调整静态瀑布流位置。
2. **既有隐患**：`getPublishedByType` 为 `limit 1` 且无 `ORDER BY`，同类型存在多条已发布
   记录时取哪条不确定（本种子通过「已有发布即跳过」的守卫规避）。
3. 分类页库中遗留一条 2026-09-29 的空白草稿（`新建页面`，默认空轮播），本种子未动它；
   可在管理端手动清理。
4. 管理端「商城装修 → 微页面」列表里会出现「分类页装修」「个人中心页装修」两条已发布记录，
   运营可直接编辑后重新发布（发布后新 versionId，种子不会覆盖运营版本）。

| 套系 | 风格参照 | 首页要点 | 分类页 | 个人中心 |

| 大促狂欢 | 618/双11 | 红页头+秒杀/拼团/折扣满配+金刚区+疯抢排行 | 轮播+秒杀+热卖榜+疯抢好货 | 开业大促 banner+促销公告 |

统一 `industry_tag=电商零售`（市场筛选项为静态枚举）、`system_flag=1`（系统模板，租户不可改删）、
`market_status=1`（已上架，跨租户可见）、`template_type=0`（整页模板）、schema v3。

### 数据链路要点

- 模板市场列表 `GET /pagedesign/templates/market/list` 跨租户（Mapper `@InterceptorIgnore`），
  仅取 `market_status='1'`；设计器「页面模板」弹窗 `GET /pagedesign/templates?pageType=x`
  匹配 `page_type IN ('2', x)`——因此模板的 `page_type` 直接写 '1'/'3'/'4'，各页设计器只会
  看到自己的那一份（字段注释只写了 0/1/2，实际 3/4 全链路可用）。
- 「使用模板」= `designer.reset(整文档替换草稿)`，模板内容为完整 v3 文档；
  「下载模板」= 复制为当前租户新模板（market_status 归 0）+ 源模板下载量 +1。
- 系统模板不可在 UI 上架/下架/删除（`requireMutableTemplate` 拦截），预置即终态。

### 种子与验证

- 种子：`db/boot/103page_design_template_market_seed.sql` / `db/cloud/104page_design_template_market_seed.sql`
  （按主键判缺插入，幂等），已登记 build-full-sql 并重建 `aryn_boot_full.sql`。

## 七、修复「模板下载后无法使用」的断链（同日追加）

问题：模板市场点「下载」后只是复制为租户模板（page_design_template），而「我的模板」
唯一的入口藏在设计器的「页面模板」弹窗里——必须先有一个页面才能进设计器；
下载后跳转的微页面列表展示的是 page_design 实例，模板完全不可见，用户断在半路。

修复（仅管理端，无后端/SQL 改动）：

- 微页面列表「新建页面」下拉新增**「从模板新建」**：
  `page-design/components/template-create-dialog.vue` 弹窗按页型聚合查询本租户模板
  （'0'/'1'/'3'/'4' 各查一次后按 id 去重），选中即 `addObj`（携带模板内容落草稿）并
  进入设计器。页型落位规则：首页模板('1')与通用模板('2')落为**微页面**（createPage
  拒绝直接建 pageType='1'；微页面无组件白名单，发布后可「设为首页」），'3'/'4' 原样。
- 落库口径与设计器「页面模板 → 使用」一致：`migratePageContent(template.templateContent)`
  迁移成 v3 文档再写入 page_content（设计器 loadPage 也会再迁移一次，双保险）。
- 模板市场「下载」成功提示改为引导文案：「已下载到我的模板，可在微页面 → 新建页面 →
  从模板新建中使用」。
- 纯函数（页型落位 + 跨页型去重合并）抽在 `template-create-utils.ts` 并配 5 项单测。

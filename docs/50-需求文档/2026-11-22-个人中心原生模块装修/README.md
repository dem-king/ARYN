# 个人中心原生模块装修

商家在个人中心页设计器中配置页头与会员、资产条、订单、常用服务、角色工作台和底部推荐。配置保存在现有装修文档的 `page.userCenter` 中，经草稿、预览和发布链路生效。历史文档缺省时按页面默认值展示。

## 实施计划

1. 在管理端和 UniApp 定义相同的设置字段、默认值和归一化规则，并覆盖历史文档。
2. 在设计器增加原生模块设置和画布快捷入口，提供排序、样式选择和恢复默认。编辑画布与草稿预览复用同一个手机骨架。
3. 在移动端将配置应用到原有模块。账号数据、订单状态、未读数和工作台资格继续使用既有数据及守卫。
4. 验证草稿往返、旧文档、两端预览规则、推荐请求和 Boot/Cloud 路径。

## 商家操作

在「商城装修 → 微页面」打开个人中心页，选右侧「原生模块」，也可以点画布卡片上的编辑图标。预览身份支持个人会员、游客、企业会员和工作台示意。排序可拖拽，也可用上移、下移按钮。支持逐项或全部恢复默认，保存与发布沿用页面装修流程。

| 模块 | 配置项 |
|---|---|
| 页头与会员 | 商城主题、渐变、素材图，会员徽章样式，中英文登录引导与权益说明 |
| 个人资产 | 卡片样式，优惠券、积分、余额的顺序 |
| 我的订单 | 中英文标题、卡片样式、各订单入口图标 |
| 我的服务 | 预设入口增删与排序、图标、每行 3 至 5 项 |
| 角色工作台 | 船舶、配送及销售入口的排序、图标和样式 |
| 猜你喜欢 | 显隐、中英文标题、系统推荐、会员专区或出清专区 |
| 运营区 | 整区置于订单上方或服务下方，历史默认位置为订单上方 |

## 验证

- Chromium 使用模拟接口，分别在 Boot 和 Cloud 配置下验证六类原生模块编辑、预览身份切换、拖拽、草稿重开、草稿预览、恢复默认和无运营组件时的发布。
- UniApp H5 使用发布快照验证游客不显示个人资产和角色工作台、服务重排、运营区移动、会员专区查询及关闭推荐时不发商品请求。
- 管理端和 UniApp 类型检查通过，UniApp 2021 项单测通过，微信小程序 Boot 和 Cloud 均构建成功。管理端装修定向用例中 423 项通过，商品瀑布流和多 Tab 商品流存在 2 项已知样式基线失败。
- 真实租户发布和微信真机尚未验收。

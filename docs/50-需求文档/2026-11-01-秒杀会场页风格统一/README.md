# 秒杀会场页风格统一（C 端）

> 日期：2026-11-01 ｜ 范围：C 端移动端 `aryn-mall-uniapp/src/pages/promotion/seckill.vue`（单文件） ｜ **零后端 / 零接口 / 零 DB**
> 原始请求：用户在微信小程序截图反馈「这个页面的风格跟其他页面风格不一致，感觉看着有点不舒服」。
> 方向拍板：用户在三个方案中选定 **A 白顶栏 + 品牌色信息卡**（B 仅修硬伤、C 全白克制未选）。

---

## 1. 诊断（代码 + 截图 + H5 计算样式三重取证）

页面视觉停留在此前 10-23「营销会场页 UI 重构」的结果，此后全站又经历了 10-24 会员中心、10-26 折扣页浮动玻璃卡、10-27 沉浸式导航、10-29 业务页顶栏磨砂玻璃四轮改造，秒杀页被明确列入「保持原状 12 页」后没有再对齐。

| # | 现象（用户可感知） | 证据 |
|---|------|------|
| D1 | 状态栏黑字压在饱和橙底上，同屏导航标题却是白字 | 用户截图像素采样：状态栏文字 `(0,0,0)`；`definePage` 未设 `navigationBarTextStyle:'white'`，`src/theme.json` 默认 black（个人中心/登录页均有该行，注释写明理由） |
| D2 | 导航右侧「活动规则」与居中标题粘连，读成「限时秒杀 活动规则」 | MP 胶囊避让后右槽仅剩约 40px；截图实测标题右缘与「活动规则」左缘间距约 5.5pt；个人中心 10-24 已有同结论（把带文字按钮移出导航） |
| D3 | 满幅品牌色头 + 无收口：导航 44px 实心 `#ff5500` + 信息条 176rpx，占首屏约 1/3 | 全站 50 个业务页已接 `useFrostedNavbar()`；同门折扣页已是白顶栏 + 白玻璃活动卡 |
| D4 | 纯黑倒计时分格 `#1F2329` 压橙底，全站唯一 | 折扣页倒计时为一行文字；其他页无黑色块 |
| D5 | 每张卡底部一条 0% 空灰轨道 + 橙色「限量 N 件」 | H5 实测 `.prog-fill` 宽 0、轨道 172×6px 灰条；进行中 4 张卡全部如此，像没加载完 |
| D6 | 一卡 4 处主色（立省角标/价格/CTA/进度文案），且同一主色有实心、180° 渐变、135° 渐变三种画法 | 主色元素计数 57（同批 H5 基线） |
| D7 | 卡片投影比购物车/折扣页重 | `0 8rpx 24rpx rgba(0,0,0,.05)` vs 购物车 `0 2rpx 12rpx`、折扣页无阴影 |
| D8 | 待开始场次全部同款灰 pill，看不出正在看哪一场 | 场次轴只按 `status===1` 区分样式 |
| D9 | 首屏加载骨架与真实首屏差约 69rpx，加载完跳一屏 | 骨架 hero 176rpx / 真实 123rpx（旧版） |
| D10 | 底栏缺安全区让位 | `.load-more` 固定 `60rpx`，home indicator 可压住最后一张卡 |

## 2. 改造规格（before → after）

| 区块 | before | after |
|------|--------|-------|
| 顶栏 | 实心主色导航 + 右槽「活动规则」文字 | `hr-navbar` 白底深字（默认分隔线），右槽移除（与购物车/分类/折扣页同口径） |
| 状态栏 | 黑字压橙底 | 顶栏转白后黑字自然正确（**不需要**再改 `definePage`/`pages.json`，避开 10-29 记录过的平台拆条风险） |
| 活动规则 | 导航右槽 4 字 | 信息卡内白 20% 玻璃胶囊 + 细箭头，热区 88rpx |
| 信息条 | 满幅 176rpx 品牌渐变，无圆角 | inset 24rpx 的**信息卡**：24rpx 圆角、`linear-gradient(180deg, primary, secondary)`（与个人中心/会员中心同一写法）、`0 10rpx 28rpx rgb(20 29 45 / 10%)` 投影 |
| 倒计时 | `#1F2329` 黑格 + 白字，label 在右上 | 卡内**白色胶囊条**（白 94%）+ 品牌色等宽数字 30rpx/800；label 20rpx `#5b616e`；跨天场次「N 天」单独一段 |
| 在抢人数 / 开抢提醒 | hero 另起两行，白字压渐变浅端 | 收进白色胶囊条右端：「N 人在抢」20rpx `#8a8f99`；「开抢提醒」为品牌实心小胶囊（对比度安全） |
| 场次轴 | pill h60；激活 135° 双色渐变；待开始 `#8a8f99`（3.0:1） | pill h64；激活**实心主色** 24rpx/700；待开始 `#5b616e`（5.6:1）24rpx/500；**新增选中态**：选中的待开始场次主色描边 + 主色字 |
| 商品卡 | 圆角 20rpx；`0 8rpx 24rpx rgba(0,0,0,.05)`；角标 12rpx/36rpx；品名 25rpx | 圆角 24rpx；`0 2rpx 12rpx rgb(15 23 42 / 4%)`（购物车行卡同档）；角标 10rpx/34rpx（对齐拼团卡）；品名 26rpx/36 行高 |
| 进度区 | pct=0 仍渲染空轨道；文案恒为主色 600 | pct=0 **不渲染轨道**，只出「限量 N 件」；文案常规 `22rpx/500 #8a8f99`，仅 `low`（仅剩 N 件）/售罄升主色 600 |
| 骨架 | 176rpx 灰块 + 116rpx 面板；卡片圆角/投影旧值 | 180rpx 卡同形 + 16rpx 轴 + h64 pill；卡片骨架同步圆角/投影，加载完不跳屏 |
| 收尾 | `padding-bottom: 60rpx` | `calc(40rpx + env(safe-area-inset-bottom))` |
| 价格 | 42rpx/800 | **不动**（秒杀 = 强促销分层，有意高于折扣页 38rpx/700） |
| CTA | h64 渐变胶囊「抢」 | **不动**（全站主按钮同为 secondary→primary 渐变） |

**主色纪律**：一屏内主色只出现在「信息卡 + 一张选中的场次 pill + 每卡 3 处（角标/价格/CTA）」，颜色全部走 `--wot-color-theme-*` token；渐变浅端只落在卡片底部装饰区，小字不上渐变（多租户浅副色下仍可读）。

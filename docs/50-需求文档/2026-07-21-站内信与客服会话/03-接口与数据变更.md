# 接口与数据变更

## 后端模块

```text
aryn-message/
├── aryn-message-api
│   ├── dto/vo/enums/entity
│   └── remote
└── aryn-message-biz
    ├── controller/admin
    ├── controller/staff
    ├── controller/app
    ├── service/mapper/dubbo
    ├── websocket
    ├── listener
    └── job
```

Cloud 路由前缀为 `/message/**`；Boot 模式沿用项目现有路径改写，通过 `/boot/**` 访问同一 Controller。

## 核心表

### `message_notice`

保存通知标题、摘要、正文、分类、优先级、来源类型、来源幂等键、目标端、受众快照、发送人快照、发布状态、发布时间、过期时间、安全跳转信息和审计字段。

### `message_recipient`

保存 `message_id`、`recipient_type`、`recipient_id`、已读状态、已读时间、接收时间、收件箱状态和审计字段。唯一索引：

```text
tenant_id + message_id + recipient_type + recipient_id
```

### `message_dispatch_task`

保存目标端、受众类型、受众条件快照、游标、成功/失败数、状态、重试次数和错误摘要。群发任务必须支持进程中断后的恢复。

### `message_conversation`

保存会话类型、客服池、会员 ID、当前负责人、状态、最后消息序号、最后消息时间、关闭时间、重开截止时间、业务上下文、活跃唯一键和审计字段。

### `message_participant`

保存参与者类型、参与者 ID、最后已读序号、加入时间、退出状态和通知设置。

### `message_chat`

保存会话 ID、序号、发送人类型/ID/名称快照、消息类型、内容或结构化负载、客户端幂等号、引用消息 ID、撤回状态和审计字段。关键唯一索引：

```text
tenant_id + conversation_id + seq_no
tenant_id + sender_type + sender_id + client_message_id
```

### `message_agent`

保存客服工作人员 ID、启用状态、自动接待开关、最大活跃会话数、当前活跃会话数、最后分配时间和乐观锁版本。在线、忙碌和暂停等实时状态放入 Redis，并以数据库配置为边界。

### `message_assignment_log`

保存自动分配、领取、转交、强制分配、关闭、重开和主管介入记录，提供审计和问题追踪。

## 管理接口

建议前缀：`/message/admin/**`。

- 通知分页、详情、草稿新增/修改、发布、撤回。
- 通知收件明细和阅读统计。
- 客服资格、接待上限和自动接待配置。
- 会话全量查询、强制分配、转交、关闭和审计日志。
- 群发任务状态和失败重试。

权限建议：

```text
message:notice:page/get/add/edit/publish/revoke
message:notice:recipient
message:service:agent
message:service:supervisor
message:conversation:page/get/initiate/claim/transfer/close/intervene
message:staff:direct
```

## 工作人员接口

建议前缀：`/message/staff/**`。

- 通知收件箱、最近通知、未读数、已读、全部已读、隐藏。
- 客服工作台待领取、我的会话、历史会话、领取、转交、关闭。
- 工作人员私信列表、消息分页、发送、已读。
- 客服上线、暂停、恢复、下线和心跳。
- WebSocket 连接鉴权和离线补拉游标。

## C 端接口

建议前缀：`/message/app/**`。

- 通知收件箱、详情、未读数、已读、全部已读、隐藏。
- 创建或获取默认客服会话。
- 会话列表、详情、消息游标分页、发送、已读、关闭、重开。
- 从通知、商品、订单或退款上下文发起咨询。
- WebSocket 连接鉴权和离线补拉。

所有 C 端接口都从安全上下文获取 `MALL_USER` 身份，所有工作人员接口都要求 `SYS_USER` 身份，禁止接受客户端指定当前参与者 ID。

## 跨域接口

### 用户域

在 `aryn-user-api` 增加面向消息域的受众游标查询接口，支持：

- 全部有效会员。
- 指定会员 ID。
- 会员等级。
- 会员标签。
- 返回消息展示所需的最小资料快照。

### UPMS

在 `aryn-upms-api` 增加工作人员受众和客服资格查询接口，支持：

- 全部有效工作人员。
- 指定工作人员。
- 角色、部门。
- 校验工作人员是否属于当前租户并拥有客服权限。

消息域不得直接连接 `aryn_user` 或 `aryn_upms` 数据库，也不得依赖对应 biz 模块。

## 业务通知事件

订单、支付、退款、营销等模块在本地事务提交后向 RocketMQ 发送 `MessageSendCommand`，至少包含：

- `eventId`：全局幂等键。
- `tenantId`。
- `recipientType`、`recipientId`。
- `category`、`templateCode` 或标题/正文。
- `bizType`、`bizId`。
- 安全业务卡片数据。

消息服务以 `eventId` 或来源唯一键防止重复消费。业务通知只能作为信息展示，订单和退款详情仍是业务状态权威来源。

## 认证、租户和部署变更

- 为安全上下文增加可靠的 TOB/TOC 登录端识别，不能复用 `ArynUser.type`。
- 新增 `aryn-message-biz-dev.yml`、`aryn_message` Cloud 数据库、Gateway 路由和 Docker 服务。
- 根 POM 和 `aryn-boot` 聚合新模块。
- Boot/Cloud SQL 同步新增消息表、菜单、权限和存量租户授权迁移。
- `TenantConfigurationConsistencyTest` 登记 `aryn-message-biz-dev.yml -> aryn_message`，并校验所有含 `tenant_id` 的消息表。

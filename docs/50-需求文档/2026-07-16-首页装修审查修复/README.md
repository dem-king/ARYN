# 首页装修审查修复

## 范围

- 后端首页初始化、首页切换、租户锁、事务提交后缓存失效和历史重复数据兼容。
- 管理端微页面操作、首页装修保存流程、组件拆分和轮播图属性契约。
- UniApp 优惠券接口参数、优惠券公共样式和分类导航样式映射。

## 验收标准

- 同租户并发初始化只创建一条首页记录，首次创建后不残留空首页缓存。
- 首页切换在同一事务内完成，缓存只在提交成功后失效。
- 微页面列表不再提供互斥的“设为首页”操作。
- 首页保存失败时恢复 loading，且只在保存成功后通知其他窗口。
- 优惠券领取使用现有分页接口和 `couponId`，优惠券与分类导航消费装修样式。

## 代码核对结论

- `page_design.page_type` 作为首页与微页面的类型来源，Boot/Cloud SQL 同步补列并迁移现有首页。
- 首页读取使用 `page_type = '1' limit 1`，兼容历史重复数据。
- `getOrCreateHomePage` 使用租户级 Redisson 锁，锁内二次查询后再创建，并清理负缓存。
- 首页切换与缓存失效集中在 service；事务存在时锁在事务完成后释放，缓存于提交后删除。
- 管理端首页编辑器拆分为组件面板、手机预览、设置面板和状态 composable。

# 采购主体自助化与绑定免审（2026-11-14）

> 本文是 2026-11-14 产品讨论的落地口径。四条决策相互关联，必须一起改，不能只改一端。

## 1. 决策清单

| 编号 | 决策 | 影响面 |
| --- | --- | --- |
| D1 | 工厂不再是采购的前置条件，工厂/企业/园区餐厅平级；「所属工厂」选填 | 主体模型、绑定页文案 |
| D2 | 船舶绑定、采购主体绑定都不走管理端审核，小程序自助完成 | 后端状态机、管理端页面定位 |
| D3 | 注册环节不采集营业执照、统一社会信用代码 | 前端表单、管理端列、文档 |
| D4 | 首单权益与「审核通过」解耦，改由运营发放 | 促销引擎（P1，本期只留口径） |

一句话原则：**谁签合同、谁付款、发票开给谁 → 采购主体；货送到哪、怎么进厂 → 收货点。**

## 2. 主体模型（D1）

`buyer_org` 保持扁平，不新增 `parent_org_id`：

| 场景 | 主体 | 餐厅的角色 |
| --- | --- | --- |
| 工厂自营餐厅 | 工厂（`org_type=2`） | 收货点/档口，不单独算首单 |
| 外包餐厅 | 园区餐厅（`org_type=3`），独立主体 | 主体本身 |
| 一家承包方开多个厂 | 一个园区餐厅主体 + 多个收货点 | 收货点 |

- 「所属工厂」只作为名称快照/备注，不参与权限与首单判定；
- 不要求先建工厂再建餐厅，创建页不出现「工厂」必填项。

## 3. 船舶绑定（D2）

| 情形 | 处理 |
| --- | --- |
| IMO 或呼号唯一命中在营船 | **提交即通过**，落 `vessel_member`，`bind_source=APPLY_AUTO` |
| 仅船名精确唯一命中 | **提交即通过**，便于事后按 `bind_source` 复核 |
| 强键/船名都未命中 | 落「待认领」，运营建船后自动通过，用户无需再操作 |

- 角色只允许 `CREW` / `CONFIRMER` / `SALES`，不允许通过申请拿到 `OWNER`；
- 邀请码路径保持现状（已是免审）；
- 管理端 `绑定申请` 页保留，定位从「审核队列」改为「认领池 + 事后回收」。

## 4. 采购主体绑定（D2）

| 情形 | 处理 |
| --- | --- |
| 创建主体 | 落库即 `audit_status=1`，`bind_source=SELF_SERVICE`，创建人即厂长 |
| 搜索加入已有主体 | **免审直接加入**，默认角色 `采购员`（`can_confirm=0`） |
| 邀请码加入 | 保持现状，免审 |
| 停用/驳回/移除 | 保留，作为事后处置 |

- 加入者默认 `can_confirm=0`：可以加购、改数，但**不能提交整单**，这是免审下的天然闸门；
- 需要采购确认权的，由厂长在成员管理里单独授予；
- 一个用户最多创建 3 个主体；
- 判重不再依赖信用代码：名称归一化 + 地址 + 手机号模糊命中时提示「可能已存在，去申请加入」，不硬拦。

## 5. 证件采集（D3）

- 注册/绑定环节只采集：主体名称、类型、地址、联系人、手机号；
- 联系人、手机号默认取当前登录账号，不要求二次填写；
- 信用代码与执照**移到开票/账期环节按需补收**：申请企业发票或账期时再填，不申请永不采集；
- `buyer_org.credit_code` / `license_url` 字段保留（nullable，唯一索引允许多个 NULL），不再出现在创建表单；
- 管理端列表、详情、筛选去掉信用代码，只留名称/类型/地址/状态。

## 6. 首单权益（D4，本期只定口径）

`audit_status=1` 现在是企业首单的判定条件（`RemoteBuyerProfileServiceImpl` 按 `buyer_org_audit_status=1` 统计）。免审后所有自助主体自动满足，等于人人可领。

处置口径：

1. **本期**：首单活动维持现状但**不自动发**，由运营对已触达客户发券（活动侧配置，不改引擎）；
2. **下一期**：`buyer_org` 增加权益标记列，引擎改判该列，不再看 `audit_status`；
3. 过渡期兜底：满减封顶 800、一人最多 3 个主体、按收货地址去重发放。

> 本期不改促销引擎，避免与正在进行的首单 P1 改造冲突；但上线前必须确认首单活动未对「自助创建主体」自动生效。

## 8. 验收

- 船员提交绑定：IMO 命中的申请返回 `status=2` 且成员表有记录；
- 主体创建：返回即 `audit_status=1`，管理端不再有待审核记录；
- 搜索加入：直接成为成员，角色采购员、`can_confirm=0`；
- 创建表单只剩 5 个字段，不再出现执照/信用代码；
- `mvn test -pl aryn-boot -am` 与 `pnpm check:type` 通过。

## 9. 明确不做

- 不做工厂与餐厅的父子层级；
- 不做船舶自助建船（新船仍需运营建档，只是不用再点「审核通过」）；
- 不做证件 OCR/工商核验；
- 不改首单引擎（下一期）。

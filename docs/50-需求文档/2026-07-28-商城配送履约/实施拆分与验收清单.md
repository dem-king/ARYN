# 实施拆分与验收清单

## 分阶段实施

### 阶段一：数据模型和状态机

- 新增配送任务、配货明细、凭证、操作日志和配送范围表。
- 新增配送状态枚举、状态转换服务、条件更新和幂等约束。
- 支付成功时幂等创建任务，确认取货时联动订单和订单项。
- 接入取消、退款、退回确认和自动确认收货。

### 阶段二：员工、素材和消息通道

- UPMS 提供配送员候选和资格校验 Dubbo 契约。
- 新增员工微信绑定、配送凭证素材上传和受控访问能力。
- 消息域接收配送派单命令，落库员工通知并实时推送。
- 新增微信订阅通道任务、错误分类、退避重试和恢复任务。

### 阶段三：管理后台

- 订单列表和详情接入商城配送摘要与派单入口。
- 新增配送任务列表/详情、派单、改派、异常处理和退回确认。
- 新增配送范围配置。
- 同步动态菜单、按钮权限、套餐和存量租户授权。

### 阶段四：客户商城

- 结算页接入商城配送可用性和第三种配送方式。
- 订单列表/详情接入公开配送进度、凭证和确认收货。
- 保持快递、自提和旧客户端兼容。

### 阶段五：配送员小程序

- 新建独立 UniApp 项目和 TOB 登录边界。
- 实现任务工作台、消息、配货、取货、导航、送达和异常页面。
- 接入员工微信绑定、订阅授权、WebSocket 和弱网重试状态。

### 阶段六：双模式与上线验收

- 同步 Boot/Cloud SQL、租户配置、字典、菜单和全量 SQL 构建清单。
- 执行后端、管理端、客户 UniApp、配送 UniApp 和 SQL 门禁。
- 在集成环境验证 MySQL、Redis、RocketMQ、XXL-JOB、对象存储和微信订阅消息。

## 核心验收标准

1. 没有配送范围配置的租户不能选择商城配送。
2. 配送范围内地址可选择商城配送，范围外地址在结算和创建订单时均被服务端拒绝。
3. 商城配送沿用现有运费规则，订单金额、退款金额和下游事件口径不新增第二套运费。
4. 相同订单的重复支付回调只生成一张配送任务和一组配货明细。
5. 管理员只能指派当前租户、账号启用且拥有配送执行权限的员工。
6. 两名管理员并发派单或改派时只能有一个请求成功。
7. 派单成功后员工消息中心必有一条幂等通知；WebSocket 和微信发送失败不回滚任务。
8. 配送员只能读取和操作当前指派给自己的任务，改派后原配送员立即失去隐私访问权。
9. 商品未全部勾选时不能确认取货；确认取货事务同时更新任务、订单和订单项。
10. 送达时必须关联 1 至 6 张本人上传的有效 JPEG/PNG，跨租户、跨员工或重复占用素材被拒绝。
11. 配送员重复提交取货、送达或异常不会重复写状态、凭证或日志。
12. 配送员送达后订单仍为待收货；客户确认或从 `delivered_at` 起超时后才完成订单。
13. 异常、改派和再次配送按 `attempt_no` 保留历次人员、原因、图片和操作记录。
14. 取货前全额退款关闭任务；取货后任一退款申请都暂停整单配送，必须进入待退回并由管理员确认商品返回。
15. 客户只能查看本人订单的公开配送进度和凭证，不读取内部异常、员工电话或后台操作信息。
16. 管理员、配送员和客户三类接口分别强制 TOB 管理权限、TOB 配送权限和 TOC 订单归属。
17. S3 和本地存储均不能通过配送接口暴露长期公共凭证 URL 或存储密钥。
18. Boot/Cloud 表结构、租户表登记、字典、菜单和权限一致。

## 自动化测试范围

### 后端

- 配送状态机所有合法和非法转换。
- 支付事件幂等、任务唯一性和明细创建原子性。
- 派单/改派并发、员工资格、租户传播和停用账号。
- 配货完整性、取货事务、送达素材校验和重复请求。
- 异常重试、退款前置退回、部分退款和全额退款。
- 商城配送自动确认基准时间与快递订单兼容。
- 消息命令幂等、通道任务重试、微信终止错误和临时错误。
- 素材真实 MIME、大小、上传人、租户、占用和访问授权。
- 素材预占、事务后确认、重复确认、订单事务回滚和绑定恢复任务。
- Mapper SQL 在多租户拦截器改写后的有效性。

### 管理后台

- 配送方式显示和派单按钮条件。
- 任务筛选、派单/改派表单、异常和退回确认。
- 权限指令、并发冲突刷新、敏感字段可见性。
- 配送范围去重和地区层级交互。

### 客户 UniApp

- 配送方式可用性、地址变化重算和创建请求载荷。
- 配送进度映射、内部字段过滤、凭证刷新和确认收货。
- 快递和自提既有流程回归。

### 配送 UniApp

- TOB Token 持久化和配送权限保护。
- 任务分页、状态刷新、WebSocket 通知后的补拉。
- 配货勾选、确认取货门禁、图片数量和提交幂等号。
- 异常表单、上传草稿、改派后访问失效和微信授权降级。

### SQL

- Boot/Cloud 建表、索引、字典、菜单和权限令牌一致。
- 新增租户表全部进入配置一致性测试。
- 全量 SQL 来源段、建表数量、DROP 覆盖和 LF 编码通过校验。

## 上线前检查

- 在备份克隆库演练 Boot 和 Cloud 增量 SQL，确认无存量唯一键冲突。
- 为每个启用租户配置配送范围、配送员角色权限、配送小程序账号和订阅消息模板。
- 验证存量套餐和角色得到预期菜单，普通员工不会获得配送执行权限。
- 验证 Gateway/Boot 两种路径下 TOB、TOC 和 WebSocket 认证。
- 验证 Redis、RocketMQ、XXL-JOB 和消息服务重启后的通知恢复。
- 验证微信拒绝授权、模板失效、频控、网络超时和 openid 解绑场景。
- 验证对象存储私有桶、本地存储代理、短期访问过期和临时素材清理。
- 验证日志、异常摘要和监控不包含完整电话、地址、openid、token 或存储密钥。

## 需要真实环境验证的项目

- 微信小程序独立 AppID、员工 openid 绑定和真实订阅消息到达。
- 地图导航拉起与不同手机系统兼容。
- 真实 S3/MinIO/OSS 与本地存储的受控图片访问。
- 弱网、图片上传中断、重复点击和小程序进程被杀后的恢复。
- 多实例 WebSocket/Redis 推送和 RocketMQ 重复投递。

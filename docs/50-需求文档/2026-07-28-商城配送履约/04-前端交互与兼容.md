# 前端交互与兼容

## 管理后台

### 订单列表与详情

- 配送方式字典增加“商城配送”。
- 商城配送待发货订单显示“派单”，不显示第三方快递发货弹窗。
- 订单详情展示配送任务号、配送员、当前状态、状态时间线、异常、退回记录和送达凭证。
- 第三方快递和上门自提页面行为保持不变。

### 配送任务

- 列表页使用状态分段控件：待派单、进行中、异常/待退回、已送达、已关闭。
- 筛选条件包括任务号、订单号、配送员、收货人、区域和时间。
- 派单弹窗展示配送员姓名、状态和当前进行中任务量。
- 改派、关闭异常和确认退回均使用独立确认对话框，原因或备注按规则必填。
- 详情页为未嵌套卡片的工作面板，展示订单商品、收货信息、任务时间线、历次配送尝试和凭证。

### 配送范围

- 支持按省/市/区县选择配送白名单，显示启用状态。
- 阻止同一租户重复配置同一行政区编码。
- 删除使用逻辑删除；已有订单不因范围配置变化而失效。

### 动态菜单

- 新增“配送任务”和“配送范围”页面、按钮权限和套餐关联。
- 派单入口既受按钮权限控制，也由后端权限重新校验。

## 客户 UniApp

### 结算页

- 配送方式增加“商城配送”。
- 已选择地址在配置范围内时才可选择；不可用时展示简短原因。
- 商城配送与普通快递一样显示现有运费。
- 地址或配送方式变化后重新请求服务端结算，客户端不自行判断最终可用性。

### 订单列表与详情

- 商城配送订单在待发货阶段展示“待派单/配货中”等配送摘要，但订单筛选仍使用现有订单主状态。
- 订单详情展示客户可见的任务节点：待派单、配送员配货、配送中、已送达。
- 不展示内部改派原因、配送员手机号、后台操作人或内部异常处理备注。
- 已送达后展示凭证缩略图和确认收货按钮。
- 图片访问失败时允许刷新短期地址，不持久缓存过期 URL。

## 独立配送 UniApp

新建 `aryn-mall-delivery-uniapp`，使用 Vue 3、UniApp、TypeScript、Alova、Pinia 和 Wot Design Uni，与客户商城保持技术栈一致但独立构建、AppID 和发布。

### 登录与绑定

- 使用 TOB 用户名/密码或现有员工短信登录，Token 存储与客户商城隔离。
- 登录后调用员工资料与配送资格接口；无权限或账号停用时清除 Token 并阻止进入工作台。
- 微信端通过 `wx.login` 获取 jsCode，在 TOB 登录后绑定当前员工与 openid。
- 在适当时机调用 `wx.requestSubscribeMessage`；拒绝授权不阻止使用任务功能。

### 工作台

- 首页显示待配货、配送中、异常/待退回和今日已送达数量。
- 任务列表支持下拉刷新、游标/分页加载和明显的状态区分。
- WebSocket 收到 `NOTICE_RECEIVED` 后刷新消息未读数和相关任务，不把推送载荷当作任务详情。

### 配货

- 详情顶部固定展示任务号、订单号、收货区域和当前状态。
- 商品清单提供稳定尺寸的勾选控件，显示图片、名称、规格和数量。
- 未全部勾选时“确认取货”禁用；后端仍执行最终校验。
- 状态变化冲突时刷新详情并提示任务已被管理员处理。

### 配送与送达

- 提供复制地址、调用地图导航和拨打电话的系统能力。
- 客户完整电话只在当前本人进行中的任务详情中按需获取。
- 送达页调用相机/相册，限制 1 至 6 张；上传完成后再提交素材 ID。
- 上传成功但提交失败时保留本地草稿，允许重试；服务端定期清理长期未关联素材。

### 异常

- 原因使用选项菜单，说明必填，图片可选。
- 提交后任务转为只读异常状态，等待管理员重新派送或改派。
- 任务改派后原配送员不能继续访问客户隐私信息。

## 视觉与可用性

- 配送端是高频工作工具，使用紧凑列表、清晰状态、固定操作区和大触控目标，不使用营销式首页。
- 重要提交按钮提供加载和防重复点击状态。
- 弱网时明确区分“图片尚未上传”“图片已上传但任务未提交”和“任务已完成”。
- 所有长地址、商品名和异常说明支持换行或省略，不能覆盖操作按钮。

## 兼容策略

- 旧客户客户端仍只展示快递和自提，不影响已有订单；服务端对 `deliveryWay = 3` 始终独立校验。
- 既有 `order_delivery`、快递100回调和微信发货信息上传保持原语义。
- 没有配送范围配置的租户默认不开放商城配送，禁止默认全区域可用。
- 微信订阅、WebSocket 或 Redis 不可用时，配送员仍可从任务列表和消息中心获取任务。
- Boot/Cloud 路径继续由环境变量切换，不在页面中硬编码部署模式。

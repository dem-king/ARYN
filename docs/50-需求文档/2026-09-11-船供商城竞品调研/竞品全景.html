竞品调研 · 悦航购船供化改造前置研究

船供数字化赛道 · 竞品全景

面向「船供公司 + 海员小程序下单 + 靠岸交付 + 大单量」业务，系统盘点国际船供 SaaS、船供电商平台、船员采购小程序与国内船供软件，回答三个问题：谁在做？能不能直接买？哪些值得借鉴？

调研范围：4 个方向 · 30+ 竞品 调研时效：2026-09 来源：官网 / 行业媒体 / 政府报道 / App Store
01

五个核心结论

先看答案，再看细节。结论基于 30+ 竞品的公开信息，标注「自称」的为厂商单方数据、未经第三方验证。

结论 1
直接竞品存在，但全球没有成熟玩家 做「海员 C 端下单」的仅 7 家（国际 3 + 国内 4），全部早期或区域化：国际的刚上线、仅限单港；国内最成熟的「长江汇」是长江内河重资产模式。国际海运船员的「小程序下单 + 靠岸交付」仍是蓝海。
结论 2
B 端软件成熟，但没有一家打通 C 端 Seaborn / Tidal / 嘉软 MTS / 多麦德 MSP 等都是纯 B 端船供商 ERP（RFQ→报价→采购→库存→财务），全部没有面向海员的下单入口。B 端管理 + C 端海员下单的闭环是你们的差异化空位。
结论 3
不建议采购通用商城 SaaS 做底座 微盟/有赞封闭、无法私有化与深度定制；ShopXO 技术栈不匹配；CRMEB 需大量自研船供流程。已有的悦航购（Spring Boot 3 + Vue 3 + UniApp 三端）已覆盖商品/订单/库存/多租户/小程序约 80% 基础能力，扩展边际成本最低。
结论 4
必做功能 = 行业入围门槛 IMPA/ISSA 编码库与自动匹配、AI 邮件/RFQ 解析、移动扫码拣货 + 照片留证、多币种对账、船员合并订单/共享购物车、到港交付预约。缺这些进不了行业牌桌。
结论 5
入驻 ShipServ / MarineOnline 补获客 两者都是纯 B2B 平台（不碰船员消费），供应商可免费/低成本入驻，分别有约 $7B 年 GMV 与 700+ 港口流量，可作为国际船供业务的获客渠道与你们的 C 端业务互补。

03

直接竞品：做「船员 C 端下单 + 到船交付」的 7 家

这 7 家与你们的业务形态最接近，是真正要盯的对手。共同点：都验证了「船员个人需求合并为整船订单」的模式；共同短板：要么区域化、要么重资产、要么未成规模。

08

对悦航购改造的建议

基于竞品调研的落地建议

  1. 坚定自研路线：基于悦航购扩展船供模块，不采购通用 SaaS、不采购纯 B 端 ERP（都缺 C 端海员下单）。
  2. MVP 优先做 C 端闭环：海员微信小程序（共享购物车 + 合并下单）→ 船供商后台接单 → 到港交付确认。B 端复杂能力（AI RFQ、WMS 扫码）二期迭代。
  3. 同步入驻 ShipServ / MarineOnline：零成本获取国际 B 端买家流量，与 C 端业务互补。
  4. 关注长江汇扩张：若从长江内河向沿海港口复制，将成为最直接对手；其重资产模式（趸船 + 无人机）在国际海运港口复制难度大，是你们的窗口期。
  5. 跟踪 Sailor's Cart：背靠 FrontM 船管 SuperApp（4000+ 船、10 万+ 海员），若从新加坡扩张到中国港口，是最具威胁的国际玩家。

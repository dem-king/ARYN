## 2. 试点数据准备

1. 试点租户开通 `business_mode=1`（个人 + 船供并存，默认值）。
2. 管理端“船舶档案”绑定 2~3 名海员商城用户为船舶成员（后台邀请授权，不开放自助搜索绑定），并指定一名采购确认人。
3. 通过商品列表“批量导入”上传 Excel：首批船供商品（含采购单位、箱规、MOQ、步长、IMPA/内部编码），确认导入后检查错误行报告。
4. 为试点商品设置销售范围（2 仅船供 / 3 两者均可）与库存。
5. 配置一个优惠券/折扣活动，验证营销快照与结算金额一致。

## 3. 端到端验收链路

### 3.1 个人购买链路

登录 → 首页工作台选择船舶（自动加载下一靠港）→ 个人购买 → 下单支付 → 仓库配货 → 派司机 → 到港 → 签收拍照。

验收点：
- 结算默认 `delivery_way=4`，页面显示船舶/港口/时间窗卡片，不出现普通快递选项。
- 司机任务详情展示船舶、港口、时间窗快照。
- 支付回调重放（重复推送同一条支付消息）只生成一个配送任务。

### 3.2 船供采购链路

登录 → 首页工作台 → 船供采购 → IMPA/中英文搜索 → 直填数量加购 → 结算（服务端重新校验 MOQ/步长/价格/库存/船舶成员）→ 支付 → 波次拣货 → 复核 → 交接司机 → 船上签收。

验收点：
- 共享购物车：发起人创建 → 成员各自加购 → 确认人核定数量提交 → 生成一个整船订单，明细保留贡献者与备注。
- 同 SKU 多成员数量合并；未达 MOQ 或非步长整数倍时提交被拦截。
- 靠港已离港（ETD 已过）后不能作为新订单配送计划。

### 3.3 履约链路（Web 管理端）

订单加入波次（同港口）→ 扫码拣货（SKU 不匹配/超量被拒）→ 短装记录原因 → 复核 → 交接司机（交接后明细锁定）→ 异常列表关闭异常。

### 3.4 司机链路（同一小程序司机模式）

已登录且有配送资格 → 免密换取司机身份 → 工作台任务 → 取货/到港/签收拍照 → 异常上报。司机 token 失效不退出海员商城。

## 4. 零售兼容回归

- 普通零售租户：地址配送（way 1/3）、优惠券、购物车、订单流程不变。
- 非船供场景（无船舶成员关系）不出现内部配送选项。
- 购买场景缺省（旧版本客户端）保持原有结算行为。

## 4.1 迭代修正：列表未自适应宽屏（2026-11-05 用户反馈）

- **现象**：角标管理页在 1600/1266 宽视口下，表格右侧留出一条空白，未撑满内容区。
- **根因**：表格 7 列全部用了固定 `width`（合计小于容器宽），Element Plus 不会把列拉伸到 100%，
  右侧自然留白；同类既有页面（如 `goods-brand`）都至少有一列使用 `min-width` 才能自适应。
- **修复**：`views/product/goods-category-badge/index.vue` 的列宽全部改为 `min-width`
  （预览 110 / 文字 120 / 底色 160 / 字色 160 / 排序 90 / 状态 90 / 操作 170），并加注释防止回退。
- **复验**：Playwright 以 1266×828@2x（与反馈截图同口径）实测，表格宽 990px、容器内容宽 1010px
  （差值即容器左右各 10px padding），已撑满；截图 `artifacts/category-badge-2026-11-05/badge-page-adaptive.png`；
  Prettier / ESLint / vue-tsc 均通过。
- **追加需求（同日）**：列表补「创建时间」列（`prop="createTime"`，min-width 170），同时把其余列收紧
  以保持 8 列总和 ≤ 990px（窄屏 1266 视口不出现横向滚动条）。复验：1266 视口表格 990/容器 1010、
  `scrollWidth=clientWidth=990`（无横向滚动）；1600 视口 1324/1344 同样撑满；截图
  `artifacts/category-badge-2026-11-05/badge-page-created-time-1266.png`。

# 活动与会员运营方案（基于 B2B 新体系的首期回填设计）

> 日期：2026-11-15　状态：方案待确认（确认后按「回填清单」执行 SQL）
> 前提：P1 全部落地（协议价/档期特供/阶梯价/满量/买赠/企业双轨均已可用）；本文所有价格基于 boot 演示库真实商品与售价设计，SKU/ID 均为库内实存。
>
> **设计原则**：
> 1. 档期化经营——活动归属「12月第1周船供备货档期」，替代整点秒杀节奏；
> 2. 单一成交价——档期特供 SKU 不与阶梯价/协议价重叠，避免展示混乱（dry-run 可预检）；
> 3. 引导批量——阶梯价按件数档、满量优惠双维度（金额/件数），服务于整箱囤货；
> 4. 权益不叠加——企业折扣与活动价取优（引擎已实现），权益是「身份感」而非「折上折」。

## 1. 会员权益设计

门槛：**沿用运营已调五档**（0.01 / 1.5万 / 3万 / 6万 / 10万，累计消费），本方案只补权益、不改门槛。建议名称语义化（运营确认后一并 UPDATE）：注册会员 → 白银海员 → 黄金海员 → 铂金海员 → 钻石海员。

| 档位 | 门槛 | 权益配置（member_benefit） |
|---|---|---|
| 注册会员 | 0.01 | 基础：下单返积分（默认口径） |
| 二档 | 1.5万 | 积分倍率 1.2 |
| 三档 | 3万 | 积分倍率 1.5 |
| 四档 | 6万 | 积分倍率 2.0 |

## 3. 专区商品设置（会员专区 / 低价捡漏区，2026-11-15 补充）

> 现状：P0 收口保留了两条系统托管活动（SYS_MEMBER_ZONE / SYS_CLEARANCE_ZONE），专区货量取决于商品打标与价格配置。实测 boot 库：会员标 48 SPU 但 **30 个未配价**（进专区无差异化价）；出清标 5 SPU 中 **3 个已到期**（实际在售仅 2 个）。两个专区都需要补货。

### 3.1 会员专区：30 个日耗品补配会员折扣率

缺价商品全量清点：时令鲜果 8 / 家常鲜蔬 8 / 猪牛羊禽 5 / 中式面点 4 / 海鲜水产 3 / 鲜面水饺 2——**全部是高频日耗生鲜食品**，正是海员日常采购场景，全量补配语义更顺（会员专区=日耗品会员价专区）。

- **配置口径**：`member_discount_rate = 0.95`（会员价=售价×0.95，如苹果 9.90→9.41）；统一折扣率便于运营心智（「会员专区全场 95 折起」），后续可对单品用 fixed 精修。
- **不动的**：已配价的 17 个 + fixed 1 个保持原值；大件低频（酒类/家电）不进会员价——差异化交给档期活动。
- **回填方式**：条件 UPDATE（只命中「标了但缺价」的行，幂等）：

```sql
UPDATE goods_spu SET member_discount_rate = 0.95, update_by='ops', update_time=NOW()
WHERE del_flag='0' AND is_member_item='1'
  AND member_discount_rate IS NULL AND member_price_fixed IS NULL
  AND tenant_id='1590229800633634816';
```

生效链路：打标/配价后由 MallZoneActivitySyncServiceImpl 同步进 SYS_MEMBER_ZONE 系统活动（每日 mallZoneSyncJobHandler 兜底）；C 端会员专区 Tab（memberItem=true）即有货有价，卡片由 useZonePrices 补会员价、未达标显示「会员专享 ¥x」引导。

### 3.2 低价捡漏区：补 5 个临期档（三档到期梯度）

出清语义「越临期越便宜」（clearance_rule 时间分层折扣叠加）。现有 2 个未到期商品保留，新补 5 个快消化商品组成三档梯度：

| 商品 | SPU ID | 售价 | 出清价 | 到期时间 | 梯度 |
|---|---|---|---|---|---|
| 小米粥杯装 350g | 9740000000000000316 | 6.90 | 4.90 | +7 天 | 近期档 |
| 流油咸鸭蛋 8枚 | 9740000000000000311 | 19.90 | 14.90 | +15 天 | 中期档 |
| 安井葱油花卷 1kg | 9740000000000000320 | 16.80 | 11.90 | +30 天 | 远期档 |
| 100%椰子水 1L/盒 | 9740000000000000225 | 12.90 | 8.90 | +30 天 | 远期档 |
| 鲜鸡蛋 10枚/盒 | 9740000000000000021 | 11.90 | 8.90 | +15 天 | 中期档 |

回填方式：UPDATE 打标 + 配价 + 到期时间（可重复执行，到期时间按执行日 +N 天动态计算）。已到期的 3 个（皮蛋瘦肉粥/奶黄包/手机支架）自然隐藏不处理。「鲜鸡蛋」同时是会员专区商品——捡漏价 8.90 低于会员价 11.30，取优后捡漏区展示更低（引擎取优口径，无冲突）。

```sql
UPDATE goods_spu SET is_clearance_item='1',
  clearance_price = 4.90, clearance_expire_time = DATE_ADD(NOW(), INTERVAL 7 DAY),
  update_by='ops', update_time=NOW()
WHERE id='9740000000000000316' AND del_flag='0';
-- （其余 4 个同构，价格/天数按上表）
```

生效链路：打标同步 SYS_CLEARANCE_ZONE（mallZoneSyncJobHandler 兜底到期退出）；出清价进 goods_sku_price_daily 快照口径（MIN 混合），近14天最低价标签自动联动。

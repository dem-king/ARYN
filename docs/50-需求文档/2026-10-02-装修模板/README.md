> 需求日期：2026-10-02

## 一、需求背景与目标

悦航购模板市场此前已有 3 套预置装修模板（种子阶段一期，固定 ID 段 …0711 等）。本次为二期扩容：在「电商零售」行业标签下，再新增 **3 套差异化成套模板 × 3 页 = 9 条**，分别对标即时零售三强（小象超市 / 盒马 / 京东七鲜）与四家属地商超 App（朴朴超市 / 叮咚买菜 / 永辉生活 / 多点 Dmall）的首页装修范式，让多商户可按自身业态（品质商超 / 社区团购 / 直播内容电商）一键套用成套页面。

目标：

1. 补齐三种典型业态的「成套」首页方案，避免商户从空白页自行拼装；
2. 每套模板固定 ID 段 `2110000000000000720–0728`，`system_flag='1'`、`market_status='1'`、`industry_tag='电商零售'`、`schema_version=3`，发布即上架模板市场；
3. 全部 9 张模板通过服务端 `DefaultPageDesignDocumentValidator` 硬校验，双模式（boot 单体 / cloud 微服务）SQL 幂等可重复执行。

### 2.3 值得悦航购借鉴的要点

1. **五段式首屏做成默认首页模板**（盒马）：搜索 → 分类 → 价格行 → 活动宫格 → 瀑布流，同时覆盖目标明确、品类明确、闲逛三类用户。来源：[盒马产品分析](https://www.woshipm.com/evaluating/5364831.html)。
2. **配色三色信号体系**：白底 + 单一品牌主色 + 红（价格/CTA）+ 黄（低价标签），主色留给商户自定义。来源：[配色网·盒马](https://www.color5.com/upload/color-scheme/32664.html)。
3. **券包阶梯解锁 + 秒杀前置**（七鲜/小象）：`coupon-combo` 逐级解锁、`seckill` 首屏强位置，是多商户拉新→复购的通用玩法。来源：[七鲜首页快照](https://7fresh.m.jd.com/?cu=true)、[美团规则中心](https://rules-center.meituan.com/rules-detail/1136)。
4. **限时紧迫感三件套**（朴朴）：场次 + 倒计时 + 库存剩余百分比 + 限购。来源：[朴朴产品分析](https://www.woshipm.com/evaluating/4401780.html)。
5. **直播从可选变必配楼层**（叮咚一级 Tab / 多点首页直播楼层）：模板提供直播楼层位置。来源：[叮咚产品分析](https://www.woshipm.com/evaluating/4337541.html)、[多点下载页](https://app.dmall.com/m/?isappinstalled=0)。
6. **到店工具区差异化入口**（多点自由购/秒付/会员码）：用宫格承载线下自提/自助结账入口。来源：[魅族应用商店·多点](https://app.meizu.com/apps/public/detail?package_name=com.wm.dmall)。
7. **分门店差异化 + 品牌色自定义 + 角色授权**（七鲜母行「鲜橙」100+ 组件拖拉拽）：这是模板市场的对标形态，决定 SaaS 装修平台商业天花板。来源：[鲜橙官网](https://o.7fresh.com/)。
8. **游戏化留存（签到/农场/果园）为现有组件缺口**：盒马小镇、叮咚农场、多点果园、朴朴朴分均把游戏化作为留存抓手，悦航购当前组件库缺失，列后续扩展。来源：[盒马产品分析](https://www.woshipm.com/evaluating/5364831.html)、[叮咚产品分析](https://www.woshipm.com/evaluating/4337541.html)。

## 四、每套模板设计说明

> 楼层顺序与组件编排均以实际模板 JSON（`new-templates/0720…0728*.json`）为准；配色参数取自 JSON 区块 `style.backgroundColor` 与页面 `page.backgroundColor`。

### 4.1 品质生活馆（0720 / 0721 / 0722）— 盒马系 · 科技蓝

**竞品风格来源**：复刻盒马「搜索 → 分类 → 价格行 → 活动宫格 → 瀑布流」五段式首屏 + 人群化楼层 + X 会员多路径植入；配色采用盒马「白底 + 科技蓝品牌色 + 红/黄信号色」范式。来源：[盒马产品分析](https://www.woshipm.com/evaluating/5364831.html)、[配色网·盒马配色](https://www.color5.com/upload/color-scheme/32664.html)。

**关键配色参数**：品牌区（页头）`#072E99`；页面底色 `#F5F6FA`；白色卡片圆角 radius 12；价格/CTA 红 `#FF2C2C`；省心价黄 `#FFB400`；点缀绿 `#8AE948`（tab-nav 指示点）。

- **首页（0720）楼层编排**（顶→底）：
  1. 品牌页头 `search-bar` + `swiper-banner`（品牌蓝 `#072E99` 底）；
  2. 服务承诺 `service-promise`（30 分钟达 / 品质保障 / 售后无忧）；
  3. 分类导航 `tab-nav`（金刚区，15 类目）；
  4. 省心价 `goods-scroll`（perView 3 横滑价格行）；
  5. 人群活动宫格 `marketing-entry`（4 入口）；
  6. 会员权益 `member-benefits`；
  7. 猜你喜欢 `goods-waterfall`（双列）；
  8. 服务公告 `notice`。
  - **编排理由**：首屏搜索 + Banner 锁定目标用户；服务承诺置顶对应即时零售「时效承诺是首屏第一信息」（小象/盒马共性）；省心价横滑行承接价格敏感人群；4 入口宫格按省钱/品质/品牌细分人群；会员权益落首页呼应盒马会员三路径；底部双列瀑布流承接闲逛用户。
- **分类页（0721）**：活动轮播 `swiper-banner` → 品质热销榜 `goods-ranking`（白卡 radius 12）→ 精选好物 `goods-waterfall`。分类页按 pageType 白名单不放搜索/金刚区/营销入口，仅保留商品与活动组件。
- **个人中心页（0722）**（页面底 `#F8F8F8`）：会员活动 `image-ad` → 领券中心 `coupon-combo`（白卡 radius 12）→ 服务公告 `notice`。

### 4.2 邻里团购（0723 / 0724 / 0725）— 朴朴/多点系 · 社区绿

**竞品风格来源**：取朴朴「限时抢购紧迫感 + 场景化楼层 + 新人专区」与多点「到店工具区/品牌卡货盘分流」。来源：[朴朴产品分析](https://www.woshipm.com/evaluating/4401780.html)、[魅族应用商店·多点（到店工具）](https://app.meizu.com/apps/public/detail?package_name=com.wm.dmall)。

## 六、覆盖范围与已知缺口（诚实列出）

1. **直播载体页未实现**：0726 首页的 `video-live` 为占位组件（mode `live`、coverUrl/liveId 留空），C 端点击提示「功能即将开放」，尚无真实直播间/回放落地页。
2. **模板图片为演示租户占位 URL**：所有 Banner/金刚区图标等图片均指向演示租户文件服务 `http://localhost:9999/boot/file/local/1590229800633634816/...`，商户上架后需自行替换为自有素材。
3. **社区自提/到店工具入口为客服兜底**：0723 首页 `marketing-entry` 的「门店自提 / 联系团长」等入口无独立自提落地页，按安全规则以 `customer-service` 兜底跳转客服会话。
4. **游戏化组件缺失**：调研发现的签到 / 果园 / 农场类留存组件（盒马小镇、叮咚农场、多点果园、朴朴朴分）当前组件库暂无对应实现，本批模板未纳入，列为后续扩展项（建议 `game-entry` / `sign-in` 方向）。

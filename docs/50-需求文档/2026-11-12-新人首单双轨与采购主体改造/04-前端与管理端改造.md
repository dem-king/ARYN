# 04 前端与管理端改造

## 1. 新人专享页：从单列表改为三轨 tab

### 1.1 页面结构

```text
[品牌渐变头卡：新人专享]
[场景 tab：个人自购 | 船上采购 | 企业采购]
────────────────────────────
个人 tab：现有资格条 + 排序 + 16 款商品卡 + 底部购物车条
船上 tab：船舶信息 + 首单资格 + 首单档位 + 去船上采购
企业 tab：工厂信息 + 审核状态 + 首单资格 + 首单档位 + 去合并采购
```

- 头卡、资格条、底部购物车条保留现有视觉；tab 放在头卡下方，白底胶囊样式，选中态用品牌色。
- 个人 tab 完全复用现有 `goods-card`、排序、规则折叠、底部 `cart-bar`，不改现有交互。
- 船上/企业 tab 不展示单品新人价，也不出现「限 1 件」；只展示订单级首单权益和入口。
- 如果用户只有个人能力，tab 可以只显示一个「个人自购」，不显示空 tab；有两个以上能力才显示分段。

### 1.2 tab 可见性与默认

新增 `src/composables/useNewbieScenes.ts`（或扩展现有 `useNewbieGoodsActions`）：

```text
输入：
- 登录态
- 船舶能力：my-vessels 返回的 memberRole/canEdit/canConfirm + 是否有可用靠港
- 工厂能力：buyer-org/my 返回的绑定主体 + auditStatus
- 最近一次下单场景（本地缓存，仅 UI 默认）

输出：
- tabs: personal / ship / enterprise
- defaultTab
- 每个 tab 的资格状态与原因
```

默认优先级：

1. 当前 `shipContextStore.purchaseScene=2` 且 `canConfirm=1` → 船上采购；
2. 当前有已绑定且审核通过的工厂 → 企业采购；
3. 其他 → 个人自购。

用户手动切 tab 后，把选择写入本地缓存；下次进入优先恢复，但资格仍以服务端为准。

### 1.3 个人 tab

保持现状：

- 资格条：游客「登录后验证新人资格 + 去登录」；登录且符合「✓ 已符合新人资格 · 注册 N 天内可享」；老客按 `ALREADY_PAID` / `REGISTER_TIMEOUT` 细分。
- 列表头「共 N 件」+「综合 / 省最多」。
- 商品卡「省¥X · 限 N 件」。
- 规则折叠四条。
- 底部购物车 + 角标 + 去购物车结算。

只加一个口径：个人新人价只对 `purchaseScene=1` 生效；如果用户从船上/企业 tab 切回个人，仍按个人资格算。

### 1.4 船上 tab

状态：

| 状态 | 展示 |
| --- | --- |
| 未登录 | 「登录后查看船供首单」+ 去登录 |
| 无船舶成员关系 | 「绑定船舶后可享船供首单」+ 去绑定船舶 |
| 有船但无可用靠港 | 「当前无可用靠港计划，申报靠港后可采购」+ 去申报 |

CTA 跳转：

- 去船上采购 → `/sub-pages/order/shared-cart/list?cartType=1` 或导入入口；
- 去绑定船舶 → 现有 `sub-pages/vessel/bind/index`；
- 去申报靠港 → 现有靠港申报页。

文案要点：

- 不写「新人价」，写「新船首单礼」；
- 明确「按船限一次，不按账号」；
- 明确「满减在订单级生效，不与单品新人价叠加」。

### 1.5 企业 tab

状态：

| 状态 | 展示 |

| 未登录 | 「登录后查看企业首单」+ 去登录 |

- 去合并采购 → `/sub-pages/order/shared-cart/list?cartType=2`；

### 1.6 聚合接口（建议）

页面进入要同时拿个人资格、船舶能力、工厂能力。为避免三个接口串行，P1 已加聚合接口（落在促销域，boot/cloud 免登白名单见 242 脚本）：

```text
GET /promotion/app/newbie/scenes
→ {
    personal: { eligible, reason, activityId, registerWithinDays },
    ship: { vessels: [{ vesselId, vesselName, memberRole, canEdit, canConfirm, hasCall }], eligible, reason },

```

如果工期紧，P1 先并行调 `my-vessels`、`buyer-org/my`、现有新人接口，P2 再收敛。

## 2. 新增「我的工厂/企业」页面

### 2.1 页面清单

| 页面 | 路径 | 作用 |
| --- | --- | --- |
| 我的工厂列表 | `sub-pages/buyer-org/list.vue` | 已绑定工厂、审核状态、当前工厂、切换/解绑 |
| 绑定工厂 | `sub-pages/buyer-org/bind.vue` | 搜索已有工厂 / 创建新工厂 / 申请加入 |
| 工厂详情 | `sub-pages/buyer-org/detail.vue` | 资料、成员、邀请码、地址、订单 |
| 申请进度 | `sub-pages/buyer-org/apply.vue` | 我的申请单状态与驳回原因 |

入口：

- 「我的」页新增「我的工厂/企业」，和「我的船舶」并列；
- 岸上共享车创建时，无工厂则弹「去绑定工厂」；
- 企业新人 tab 的 CTA。

### 2.2 绑定页交互

顶部两个模式：

```text
[创建新工厂] [加入已有工厂]
```

**创建新工厂**（2026-11-14 调整：免审核、不收证件）：

- 工厂名称（必填）
- 工厂类型（企业/工厂/园区餐厅）
- 详细地址
- 联系人（默认取当前账号昵称）
- 手机号（默认取当前账号手机号）
- 提交即创建成功；不再上传营业执照、不填统一社会信用代码；开票或申请账期时再按需补充
- 状态直接为「已通过」，不再出现「待审核」

**加入已有工厂**（2026-11-14 调整：免审核）：

- 搜索框：工厂名称；
- 结果卡片：工厂名、地址、成员数；
- 「加入」→ 免审核直接成为采购员（`can_confirm=0`：可加购改数，不能提交整单）；
- 有邀请码时，直接输入邀请码加入（免审）。

### 2.3 工厂详情

- 头部：工厂名、审核状态、当前角色、信用代码脱敏；
- 成员：头像/昵称/手机号/角色/加入时间；厂长可添加/移除/改角色；
- 邀请码：生成/复制/失效；显示有效期和剩余次数；
- 地址：默认收货地址、其他地址；
- 订单：该工厂的企业订单列表（按时间倒序）；
- 操作：切换为当前工厂、退出工厂（厂长不可直接退出，需先转让）。

## 3. 岸上共享车改造

### 3.1 创建弹层

`sub-pages/order/shared-cart/list.vue`：

- `cartType=2` 时新增「采购主体」选择器：
  - 已绑定工厂：下拉选择，显示工厂名 + 审核状态；
  - 未绑定：显示「去绑定工厂」，不允许创建；
  - 待审核工厂：可选择并创建，但提示「审核通过后享首单」。
- `cartType=1` 不显示该选择器。
- 创建请求体增加 `buyerOrgId`。

### 3.2 列表/详情

- 列表卡片：岸上车显示工厂名；历史车显示「采购主体未绑定」灰色标签。
- 详情头部：`工厂名 · 合并采购`；船供车仍以船名开头。
- 详情摘要：采购主体、收货地址、成员、截止时间。
- 历史车：可关闭、可提交（订单主体为空、不享首单）；提示运营补绑。

### 3.3 导入入口

`sub-pages/order/shared-cart/import-entry.vue`：

- 配送目标选「岸上企业」时，增加工厂选择；
- 未绑定工厂 → 去绑定；
- 导入完成后创建的车带 `buyerOrgId`。

### 3.4 API 类型

export interface SharedCartCreatePayload {

`SharedCart` 返回类型增加 `buyerOrgId`、`buyerOrgName`、`buyerOrgAuditStatus`。

## 5. 管理后台

### 5.1 采购主体管理页

路径：`apps/web-ele/src/views/order/buyer-org/`

> 分阶段：P1 先落最小审核页（待审核列表 + 详情 + 通过/驳回）；P2 再补成员管理、邀请码、停用、批量、申请单。

- 列表：工厂名、信用代码、类型、联系人、审核状态、成员数、创建时间；
- 筛选：名称/信用代码/审核状态/状态；
- 操作：详情、审核、停用、成员管理、邀请码；

- 成员管理：添加成员（手机号/用户 ID）、改角色、移除；

## 6. 兼容与降级

- 旧版本小程序不显示 tab，仍走个人新人价；岸上车创建不带 `buyerOrgId` 会被服务端拒绝，需发版/引导更新。
- 服务端 `buyerOrgId` 为空的历史车仍可查看/提交；首单统计忽略空主体。
- 管理端未配置菜单时，采购主体页不可见；先跑 SQL 再发前端。
- 首单活动未发布/已结束时，船上/企业 tab 显示「首单活动未开始/已结束」，不展示档位，但仍可去采购。

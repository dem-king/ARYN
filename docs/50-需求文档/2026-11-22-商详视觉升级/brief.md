# 银鹭花生牛奶商详视觉升级 Brief

## 目标与范围

- 目标：解决当前商品详情页连续文字堆叠的问题，让用户先被商品与饮用场景吸引，再按需查看采购规则、参数和评价。
- 当前产物：主视觉方向样图、已接入真实数据的 UniApp 商品详情页，以及 430px 手机宽度的 H5 验收截图。
- 改造只调整信息层级、展示组件和交互，不修改商品价格、优惠规则、SKU 起订逻辑、加购路径或结算接口；不涉及后端与数据库变更。

## 商品事实与来源

- 商品：银鹭花生牛奶450ml。
- 商品主图、名称、副标题、价格和参数来自当前本地 Boot 商品接口及用户提供的真实页面截图。
- 当前可见价格：¥4.90，划线价 ¥6.37；规格 450mL；2–6℃ 冷藏；21天保质期；国产。
- 服务信息：冷链直发、破损包赔、支持开票。
- 灵感文案依据：现有“花生奶香，香甜顺滑”与“小时候小卖部的味道”，主视觉候选标题为“花生奶香，一口回到小时候”。
- 商品原始主图：`prototype/assets/product-original.jpg`。图像是银鹭红白瓶身、心形 Logo、花生牛奶复合蛋白饮品与净含量标识的身份依据，不用于继承原页面的文字排版。

## 内容与视觉方向

- 受众与行为：船上个人采购与批量采购用户；先快速识别商品、规格和价格，再决定是否继续浏览。
- 情绪目标：熟悉、香甜、清爽、有生活感，避免资料表式的沉闷阅读。
- 主视觉机制：银鹭商品大图承担第一焦点；牛奶暖白形成低干扰阅读空间；银鹭红用于商品关联与行动按钮；少量花生金用于原料和氛围点缀。
- 构图：方向样图为横版，商品在右侧占据主要高度，左侧为粗体标题与低干扰奶白留白；少量花生与奶液建立口味联想，不添加未经证实的营养或功效主张。
- 字体：标题采用粗实、现代、略圆润的中文黑体方向；正文与采购信息采用中性黑体。正式 HTML 优先核验 DouyinSans 700 与 Source Han Sans SC VF，系统字体仅作回退。
- 图文分工：方向样图只包含主标题及商品原有包装文字。正式原型中的商品名、价格、参数、优惠、评价和按钮均为原生可编辑文字；商品主图与场景图不承载这些准确文字。

## 模板比较与采用

- 查询：详情页构图，主视觉＋满幅场景，优先“感官生活”；另查询场景＋满幅图片与独立文案区。
- 采用候选：`combination.cleaned-composition-detail-page-0007::section-01`。
- 发布源：`assets/模板库/构图/详情页-食品饮料-风格中性-连续场景卖点长页-高.html`。
- SHA-256：`663072ae894abebafa364fe2b2300d03c371b4469eacaf404e7f56869fa868c9`。
- 采用范围：只继承“商品与原料构成满幅场景、标题位于低干扰净空、商品为第一焦点”的主视觉关系；不继承模板商品、文案、倾斜角度、灰度配色、虚构营养信息及后续章节。
- 当前页面是 App 商品详情 UI，不照搬模板长页的屏数或高度。

## 已落地的信息结构

1. 商品主图与价格。
2. 商品名、一句话卖点、四个采购标签和三项服务。
3. “采购优惠”和“商品档案”两个紧凑入口，详细规则与参数在弹层查看。
4. 用户评价提前，场景文字卡不再挡在评价前。
5. 商品详情采用真实商品图、饮用场景与短标题，不再默认平铺大段参数和通用文案。
6. 保留底部加入购物车行动区。

# 开发工作流

> 详细开发指南参见 [DEVELOPMENT.md](../DEVELOPMENT.md)。

## 1. Git 工作流

### 分支策略

| 分支 | 说明 | 保护 |
|------|------|------|
| `main` | 生产分支 | ✅ 受保护 |
| `dev` | 开发集成分支 | — |
| `feature/xxx` | 功能开发分支 | — |
| `fix/xxx` | 修复分支 | — |

### Commit Message 规范

格式：`type(scope): description`

| type | 说明 | 示例 |
|------|------|------|
| `feat` | 新功能 | `feat(user): add user profile page` |
| `fix` | 修复 | `fix(order): correct order status transition` |
| `docs` | 文档 | `docs: update API reference` |
| `style` | 格式 | `style: fix indentation` |
| `refactor` | 重构 | `refactor(pay): extract payment strategy` |
| `test` | 测试 | `test(order): add order service tests` |
| `chore` | 构建/工具 | `chore: upgrade dependencies` |

## 2. 代码规范

### 2.1 Java 后端

**目录约定**:

```
aryn-*-biz/src/main/java/com/aryn/cloud/{domain}/
├── controller/         # HTTP 接口 (@RestController)
├── service/
│   ├── impl/           # 业务实现
│   └── xxxService.java # 接口定义
├── mapper/             # MyBatis Mapper
├── entity/             # 数据库实体 (BaseEntity)
├── dto/                # 数据传输对象
└── config/             # 模块配置
```

**关键注解约定**:

| 场景 | 注解 | 说明 |
|------|------|------|
| Controller | `@RestController` + `@RequestMapping("/{domain}")` | HTTP 接口 |
| Service | `@Service` + `@Transactional(rollbackFor = Exception.class)` | 业务实现 |
| Mapper | `@Mapper` (或启动类 `@MapperScan`) | 数据访问 |
| Entity | `@Data` + `@TableName("{table}")` + 继承 `BaseEntity` | 数据库实体 |
| 权限 | `@SaCheckPermission("user:xxx:yyy")` | 权限控制 |
| 防重 | `@RepeatSubmit` | 防重复提交 |

**代码风格**:

| 规则 | 说明 |
|------|------|
| Lombok | 使用 `@Data`, `@Slf4j`, `@RequiredArgsConstructor` |
| 统一返回 | `Result.success(data)` / `Result.failed(msg)` |
| 分页查询 | `IPage<T>` 参数 + `Result<PageResult<T>>` 返回 |
| 参数校验 | `@Valid` + `@NotNull` / `@NotBlank` |
| 日志 | `@Slf4j` 结构化日志 |
| 禁止 | `System.out.println()`, `printStackTrace()`, 硬编码密码/密钥 |

**命名规范**:

| 类型 | 规范 | 示例 |
|------|------|------|
| 类名 | PascalCase | `OrderService`, `UserAddressController` |
| 方法/变量 | camelCase | `getOrderList`, `userId` |
| 常量 | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT` |
| 包名 | 全小写 | `com.aryn.cloud.order` |

### 2.2 Vue 3 (管理后台)

| 规则 | 说明 |
|------|------|
| API 风格 | Composition API (`<script setup lang="ts">`) |
| 文件命名 | `kebab-case.vue` |
| 表单组件 | `<FormModal>` 模式（弹窗表单） |
| 权限指令 | `v-action="'user:xxx:yyy'"` |
| 公共包 | 使用 `@vben/*` 公共包而非自己写重复逻辑 |

**命名规范**:

| 类型 | 规范 | 示例 |
|------|------|------|
| 组件/类型 | PascalCase | `UserForm`, `OrderStatus` |
| 函数/变量 | camelCase | `fetchUserList`, `orderId` |

### 2.3 UniApp (移动端)

| 规则 | 说明 |
|------|------|
| API 风格 | Composition API + `<script setup lang="ts">` |
| 路由 | 页面文件路由 (`uni-mini-router`) |

## 3. 数据库规范

### 命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 表名 | `sys_` 前缀(系统) / `{domain}_` 前缀(业务) | `sys_user`, `order_info` |
| 字段名 | snake_case | `create_time`, `tenant_id` |
| 布尔字段 | `is_` 前缀 | `is_deleted`, `is_enabled` |
| 索引 | `idx_{table}_{field}` | `idx_order_info_status` |

### 必需字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 雪花算法主键 |
| `tenant_id` | BIGINT | 租户 ID |
| `create_by` | VARCHAR | 创建人 |
| `create_time` | DATETIME | 创建时间 |
| `update_by` | VARCHAR | 更新人 |
| `update_time` | DATETIME | 更新时间 |
| `del_flag` | CHAR(1) | 0=正常, 1=删除 |

> ⚠️ 所有删除操作使用 `del_flag` 逻辑删除，**严禁** SQL `DELETE` 语句。

## 4. 质量标准（三项目通用）

| 规则 | 说明 |
|------|------|
| 单文件行数 | 不超过 **500 行** |
| Java 日志 | `@Slf4j` 结构化日志，禁止 `System.out.println()` / `printStacktrace()` |
| TS/Vue 格式 | 通过 ESLint + Prettier 格式化 |
| 逻辑删除 | 用 `del_flag` 字段，禁止物理删除 |
| 事务一致性 | 涉及多表操作需保证事务一致性 |

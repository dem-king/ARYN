# 悦航购 Aetheryn Mall — 业务上下文

> 本文档帮助 AI Agent 理解电商领域术语和项目特有的业务概念。

## 1. 核心业务域

| 域 | 模块 | 业务说明 |
|------|------|------|
| **用户** | aryn-user | C端商城用户：注册/登录、会员等级、收货地址、积分、储值余额、签到 |
| **商品** | aryn-product | SPU/SKU 管理、分类、品牌、评价、收藏、浏览足迹 |
| **订单** | aryn-order | 购物车、下单、订单生命周期（待付款→待发货→待收货→已完成）、售后/退款 |
| **支付** | aryn-pay | 多渠道支付（微信/支付宝/余额）、支付流水、退款 |
| **营销** | aryn-promotion | 优惠券、满减活动、拼团、秒杀、页面装修 |
| **权限** | aryn-upms | 后台RBAC：用户/角色/菜单/部门管理（SaaS多租户） |
| **认证** | aryn-auth | OAuth 2.0 / Sa-Token 认证授权，前后台分离登录 |
| **物流** | aryn-common-logistics | 快递100/菜鸟裹裹等物流查询封装 |
| **通知** | aryn-common-sms | 短信服务（注册验证码、订单通知） |

## 2. 业务概念词典

### 2.1 商品体系
- **SPU** (`goods_spu`): 标准化产品单元，如 "iPhone 15"
- **SKU** (`goods_sku`): 库存保有单位，如 "iPhone 15 / 黑色 / 256G"
- **商品规格**: SKU 的区别属性（颜色、尺寸等），用 `specs` JSON 存储
- **分类** (`goods_category`): 商品类目树，通常 2-3 级

### 2.2 订单体系
- **购物车** (`shopping_cart`): 用户暂存商品，按 SKU 存储
- **订单状态流转**:
  ```
  待付款 → (支付成功) → 待发货 → (商家发货) → 待收货 → (用户确认) → 已完成
     ↓                     ↓
  已取消               售后/退款中 → 已退款
  ```
- **订单类型**: 普通订单、拼团订单、秒杀订单
- **售后**: 仅退款（未发货）、退货退款（已发货）

### 2.3 支付体系
- **支付方式**: `wxpay` (微信)、`alipay` (支付宝)、`balance` (余额)
- **支付流水** (`pay_trade_order`): 记录每笔支付请求和回调
- **合并支付**: 多个订单合并为一次支付
- **支付回调幂等**: 通过 `trade_no` 防重

### 2.4 会员体系
- **会员等级** (`member_level`): 根据累计消费金额/积分自动升级
- **积分** (`points_record`): 消费、签到、注册获取，可抵扣订单金额
- **储值余额** (`balance`): 用户账户余额，支持充值赠送配置
- **签到** (`sign_in_record`): 每日签到送积分，连续签到额外奖励

### 2.5 营销体系
- **优惠券** (`coupon_info` / `coupon_user`): 满减/折扣券，用户领取和使用
- **页面装修** (`page_design`): C端首页/活动页面拖拽式配置

### 2.6 权限体系 (SaaS)
- **RBAC 模型**: 用户 → 角色 → 菜单/权限
- **租户** (`tenant`): SAAS 多租户隔离，每个租户独立管理后台
- **权限编码**: `{domain}:{resource}:{action}`，如 `user:member-level:page`
- **用户类型**: `SYS_USER` (后台管理员) vs `MALL_USER` (C端商城用户)

## 3. 通用约定

### 3.1 SaaS 多租户
- 所有业务表含 `tenant_id` 字段
- 登录时确定租户，后续请求通过 MyBatis 拦截器自动注入
- 权限/菜单/角色均为租户级别

### 3.2 数据安全
- 密码: BCrypt 加密存储
- Token: Sa-Token 无状态 JWT
- 敏感信息: AES 加密传输 (前端)
- 手机号: 脱敏显示 `138****1234`

### 3.3 API 路由约定
- 管理端: `/admin/{domain}/**`  (需 `@SaCheckPermission`)
- 应用端: `/app/{domain}/**`    (需 `@SaCheckLogin`)
- 无需登录: `/auth/**` 认证接口
- 网关白名单: `/doc.html`, `/v3/api-docs`, `/auth/**`

### 3.4 字典系统
- 系统字典: `dict` 表，如 `order_status`、`pay_type`
- 前端使用 `<DictTag>` 组件渲染字典值
- UniApp 端通过 `dictStore` 全局缓存

## 4. 特殊业务规则

1. **订单超时取消**: 30分钟未支付自动取消 (XXL-JOB 定时扫描)
2. **收货自动确认**: 发货后 7 天自动确认收货
3. **退款审核**: 管理员审核通过后调支付渠道退款接口
4. **积分抵扣**: 100 积分 = 1 元，订单结算时使用
5. **优惠券叠加**: 同一订单最多使用 1 张优惠券
6. **库存扣减**: 下单时预占库存，支付成功后扣减，取消/退款后恢复

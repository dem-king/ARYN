# 业务流程

> 详细业务概念参见 [PRODUCT_SENSE.md](../PRODUCT_SENSE.md)，术语定义参见 [术语表](../00-项目总览/术语表.md)。

## 1. 核心业务域

| 域 | 模块 | 业务说明 |
|------|------|------|
| **用户** | aryn-user | C端商城用户：注册/登录、会员等级、收货地址、积分、储值余额、签到 |
| **商品** | aryn-product | SPU/SKU 管理、分类、品牌、评价、收藏、浏览足迹 |
| **订单** | aryn-order | 购物车、下单、订单生命周期、售后/退款 |
| **支付** | aryn-pay | 多渠道支付（微信/支付宝/余额）、支付流水、退款 |
| **营销** | aryn-promotion | 优惠券、拼团、分销、页面装修 |
| **权限** | aryn-upms | 后台 RBAC：用户/角色/菜单/部门管理（SaaS 多租户） |

## 2. 下单流程

```
用户浏览商品 → 加入购物车 → 选择商品结算 → 填写收货地址
    → 选择优惠券 → 选择支付方式 → 提交订单
    → [Spring Event: 订单创建前] → 创建订单 → [Spring Event: 订单创建后]
    → 库存预占 → 待付款
```

### 订单状态流转

```
待付款 ──(支付成功)──→ 待发货 ──(商家发货)──→ 待收货 ──(用户确认)──→ 已完成
  │                      │
  ↓                      ↓
已取消               售后/退款中 → 已退款
```

| 状态 | 触发条件 | 后续动作 |
|------|----------|----------|
| 待付款 | 订单创建 | 30 分钟超时自动取消 |
| 已取消 | 超时/手动取消 | 释放库存、退回优惠券 |
| 待发货 | 支付成功 | 通知商家发货 |
| 待收货 | 商家发货 | 7 天自动确认收货 |
| 已完成 | 用户确认/自动确认 | 触发积分发放、分销结算 |
| 售后/退款中 | 用户申请 | 管理员审核 |
| 已退款 | 审核通过 | 调支付渠道退款、恢复库存 |

### 订单类型

| 类型 | 说明 |
|------|------|
| 普通订单 | 标准购买流程 |
| 拼团订单 | 参与拼团活动，成团后发货 |
| 秒杀订单 | 限时抢购，库存独立 |

## 3. 支付流程

```
提交订单 → 创建支付单(pay_trade_order) → 调第三方支付渠道
    → 用户完成支付 → 第三方回调 → 回调验签 + 幂等(trade_no)
    → [RocketMQ: 支付通知] → 更新订单状态为待发货
```

### 支付方式

| 方式 | 编码 | 说明 |
|------|------|------|
| 微信支付 | `wxpay` | 支持 JSAPI/H5/Native/App |
| 支付宝 | `alipay` | 支持扫码/H5 |
| 余额支付 | `balance` | 扣减用户储值余额 |

### 合并支付

多个订单可合并为一次支付，支付成功后通过 RocketMQ 分别通知各订单模块更新状态。

### 支付回调幂等

通过 `trade_no` 防止重复处理，确保同一笔支付只处理一次。

## 4. 退款流程

```
用户申请退款 → 创建退款单(order_refund) → 管理员审核
    → 审核通过 → 调支付渠道退款接口(RemoteRefundService)
    → 退款成功 → [RocketMQ: 退款通知]
    → 恢复库存 → 退回优惠券 → 退回积分
```

### 退款类型

| 类型 | 适用场景 | 说明 |
|------|----------|------|
| 仅退款 | 未发货 | 直接退款，无需退货 |
| 退货退款 | 已发货 | 用户寄回商品，确认后退款 |

## 5. 会员体系流程

```
用户注册 → 获取初始积分 → 日常签到获取积分
    → 消费获取积分 → 积分累计 → 会员等级自动升级
    → 积分可抵扣订单金额(100积分=1元)
    → 储值余额充值 → 充值赠送(按配置) → 余额支付
```

### 积分来源

| 来源 | 积分 | 说明 |
|------|------|------|
| 注册 | 固定值 | 新用户注册奖励 |
| 签到 | 按连续天数递增 | 连续签到额外奖励 |
| 消费 | 按消费金额比例 | 订单完成后发放 |
| 评价 | 固定值 | 评价商品奖励 |

## 6. 营销流程

### 6.1 优惠券

```
管理员创建优惠券 → 设置发放规则(满减/折扣/门槛)
    → 用户领取 → 下单时选择使用 → 同一订单最多1张
```

### 6.2 拼团

```
管理员创建拼团活动 → 设置成团人数/价格/时间
    → 用户开团/参团 → [定时任务: 拼团过期检查]
    → 成团 → 生成订单 → 正常发货流程
    → 未成团(超时) → 自动关闭 → 退款
```

### 6.3 分销

```
用户申请成为分销员 → 审核通过 → 生成专属推广链接
    → 推广产生订单 → [定时任务: 分销结算]
    → 计算佣金 → 佣金提现
```

## 7. 事件驱动架构

### RocketMQ 消息

| Topic | 生产者 | 消费者 | 说明 |
|-------|--------|--------|------|
| 订单取消 | order-biz | product-biz, promotion-biz | 释放库存、退回优惠券 |
| 支付通知 | pay-biz | order-biz | 更新订单状态 |
| 退款通知 | pay-biz | order-biz, product-biz, promotion-biz | 恢复库存、退回优惠 |
| 订单完成 | order-biz | user-biz, promotion-biz | 积分发放、分销结算 |

### Spring Event

| 事件 | 触发时机 | 处理逻辑 |
|------|----------|----------|
| OrderCreateBeforeEvent | 下单前 | 校验库存、校验优惠券 |
| OrderCreateAfterEvent | 下单后 | 库存预占、优惠券锁定 |
| PaySuccessEvent | 支付成功 | 更新订单状态、发送通知 |
| RefundSuccessEvent | 退款成功 | 恢复库存、退回优惠 |

## 8. 定时任务

| 任务 | 模块 | 调度 | 说明 |
|------|------|------|------|
| 订单超时取消 | order-biz | XXL-JOB | 30 分钟未支付自动取消 |
| 收货自动确认 | order-biz | XXL-JOB | 发货后 7 天自动确认 |
| 优惠券过期 | promotion-biz | XXL-JOB | 自动过期未使用的优惠券 |
| 拼团过期 | promotion-biz | XXL-JOB | 自动关闭超时未成团的拼团 |
| 分销结算 | promotion-biz | XXL-JOB | 定期结算分销佣金 |

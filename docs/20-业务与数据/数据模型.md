# 数据模型

> 详细架构信息参见 [ARCHITECTURE.md](../ARCHITECTURE.md)。

## 1. 数据库清单

| 数据库 | 用途 | 表数量 |
|--------|------|:------:|
| `aryn_boot` | 单体模式业务库 | 全量 |
| `aryn_upms` | 权限管理库 | 17 |
| `aryn_user` | C 端用户库 | 17 |
| `aryn_order` | 订单库 | 7 |
| `aryn_pay` | 支付库 | 4 |
| `aryn_product` | 商品库 | 8 |
| `aryn_promotion` | 营销库 | 12 |
| `aryn_nacos` | Nacos 配置库 | 6 |

> 合计 **70+** 数据库表。

## 2. 公共字段规范

所有业务表含以下公共字段（通过 `BaseEntity` 基类统一管理）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 雪花算法主键 |
| `tenant_id` | BIGINT | 租户 ID（多租户隔离） |
| `create_by` | VARCHAR | 创建人 |
| `create_time` | DATETIME | 创建时间（自动填充） |
| `update_by` | VARCHAR | 更新人 |
| `update_time` | DATETIME | 更新时间（自动填充） |
| `del_flag` | CHAR(1) | 逻辑删除：0=正常，1=删除 |

## 9. 实体关系

```
mall_user ──1:N──→ user_address
    │
    ├──1:N──→ shopping_cart ──N:1──→ goods_sku ──N:1──→ goods_spu
    │                                         │
    ├──1:N──→ order_info ──1:N──→ order_item ─┘
    │               │
    │               ├──1:1──→ order_logistics
    │               └──1:N──→ order_refund
    │
    ├──1:N──→ coupon_user ──N:1──→ coupon_info
    │
    ├──1:N──→ points_record
    ├──1:N──→ sign_in_record
    └──1:1──→ balance ──1:N──→ balance_record

pay_trade_order ──1:N──→ order_info
pay_trade_order ──1:N──→ pay_refund

sys_user ──N:N──→ sys_role ──N:N──→ sys_menu
sys_user ──N:1──→ sys_dept
sys_tenant ──1:N──→ sys_user
```

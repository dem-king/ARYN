## 常见定位误区

- 管理端只有一个静态 dashboard route；业务页面能否出现还取决于 `sys_menu` 与 `/upms/menu`。
- 单体模式 URL 会从 `/domain/resource` 改写为 `/boot/resource`，不能只按浏览器最终 URL 搜 Controller。
- API DTO/Entity 可能位于 `*-api`，HTTP Controller 和实现位于 `*-biz`。
- 消息域 Cloud 前缀为 `/message/**`，Boot 模式会改写到 `/boot/**`；工作人员与会员接口分别强制 TOB/TOC 登录端，不能只凭用户 ID 判断身份空间。
- `page_design`、拼团、分销和会员模块是当前高变动区域，修改前先检查租户表配置与 SQL 增量脚本。
- 配送、秒杀和折扣活动使用 25/26 号增量 SQL；当前编号存在同号多文件，执行时必须按完整文件名确认，不能只按序号描述。

## 页面装修定位补充

- 管理端统一编辑器：`aryn-mall-ui/apps/web-ele/src/views/promotion/page-designer/`，包含 v2 schema、迁移器、组件注册表、命令历史、草稿自动保存、模板和发布流程。
- 编辑器画布：`components/phone-canvas.vue` 负责手机壳与背景/导航判定，区块列表抽在 `components/canvas-section-list.vue`，内嵌页型的原生骨架在 `components/canvas-page-shell.vue`。两条容易踩的约定：
  - **组件操作按钮必须挂在组件盒子内部**（右上角）。区块 `radius > 0` 时会内联 `overflow: hidden` 裁掉子组件直角背景，任何负偏移（如早先的 `right: -44px`）溢出的按钮都会被整块剪掉，表现为「选中的组件没有删除按钮」。`canvas-page-shell-contract.test.ts` 钉住此约束。
  - **商详(2)/分类(3)/个人中心(4) 是内嵌页型**：C 端 `DiyPage` 传 `embedded`（不渲染装修自带导航栏、不撑满 100vh），画布同构地不画 Schema 导航栏，并套一层原生骨架展示落点与真实宽度——分类页装修嵌在右栏商品流内，左栏 rail 176rpx=88px，**可用宽度只有 375-88=287px**。骨架尺寸与 C 端逐值对齐（1rpx=0.5px），改一端必须同步另一端；工具栏「页面结构」按钮可切换纯编辑视图（仅内嵌页型出现）。
  - 手机壳用 `box-sizing: content-box` + `outline` 画描边，保证内容区正好 375px；用 `border` 会让内容区只剩 373px，右栏量出来是 285px 而非 287px。
- **区块背景填充优先级**：`backgroundImage`（背景图）> `backgroundGradient`（渐变）> `backgroundColor`（纯色）。渐变由管理端 `schema/section-style.ts` 的 `buildSectionGradient` 生成 `linear-gradient(...)`（方向白名单 `to right` / `to bottom` / `135deg` / `225deg`，色值校验后拼接），C 端同源实现在 `diy/schema/section-gradient.ts`；两段函数用 `SECTION-GRADIENT` 标记圈出，`preview-parity.test.ts` 去掉空白与分号后逐字比对，改一端必须同步另一端。历史草稿缺 `backgroundGradient` 字段时按纯色渲染，旧版 C 端忽略该字段同样回落纯色。区块背景画在页面背景之上，不透明时会盖住页面背景；区块设置新增「无背景」三态之一，清空纯色与渐变后透出页面背景。
- **导航栏背景跟随首区块**（2026-10-21）：页面设置 `navigation.backgroundMode = 'followFirstSection'` 时，导航栏不再单独取色，而是自动跟随首个「有内容」区块的背景：渐变取顶边起始色（上下渐变与区块接缝同色），`to right` 渐变整段复用到导航栏（接缝逐列同色），纯色取该色；文字默认按背景亮度自动取黑/白（`textColorAuto=false` 时用 `navigation.textColor`）。背景图区块无法在导航栏内连续呈现，回落商城主题/自定义导航色。解析函数在管理端 `page-designer/schema/navigation-style.ts` 与 C 端 `diy/schema/navigation-style.ts`，用 `NAVIGATION-FOLLOW` 标记圈出、`preview-parity.test.ts` 逐字比对；编辑画布 `phone-canvas.vue`、草稿预览 `preview-canvas.vue`、C 端 `diy/index.vue` 三处渲染面统一消费。C 端 `hr-navbar` 为此新增 `backgroundImage` 入参（左右渐变复用），其余调用方缺省不受影响。
- **导航标题留空回退页面名称**（2026-10-21）：三端导航栏文案统一取 `navigation.title || 页面名称`——编辑画布 `phone-canvas.vue`、草稿预览 `preview-canvas.vue`、C 端 `diy/index.vue` / `useDecorationPage.ts`。`page_content.page.navigation.title` 为空不是草稿丢字段，画布上看到的是「页面名称」回退（左上角工具栏 input）。因此页面设置「导航标题」必须用 placeholder + 说明写出回退（面板接收 `pageName`），否则运营会误以为标题没保存；`page-settings-contract.test.ts` 钉住面板提示与三端回退链。

# 悦航购船供化二期实施计划

> 日期：2026-09-12
> 依据：`悦航购船供化彻底改造总方案.md` §12 阶段 2、§17.10 营销第二优先级
> 一期已完成：领域契约、双模式 SQL、船舶域、船供资料与 Excel 导入、订单配送上下文与支付幂等、共享购物车与整船订单、履约波次/扫码/短装/异常、Web 工作台、小程序上下文与船供目录。

## 二期范围（阶段 2 收口 + 营销二期）

| # | 任务 | 内容 | 关键约束 |
|---|---|---|---|
| P1 | 53 号增量 SQL | `promotion_activity`（统一活动：阶梯价/整船优惠）、`promotion_lock`（锁定/释放）、`order_info.promo_price`、`order_item.promo_price`、`delivery_way` 无关字典 | 双模式、幂等、登记全量 |
| P2 | 营销引擎（补一期欠账 Task 11） | `PromotionContextDTO`/`PromotionCalculationVO`/`RemotePromotionEngine`（preview/reserve/confirm/release）+ `PromotionEngineService` + `PromotionReservationService`；阶梯价按数量取最高档，整船优惠按金额取档，范围匹配（全场/场景/船舶/靠港/港口） | AI 输出与外部渠道不直接生成可支付订单；规则快照入订单 |
| P3 | 交易接入 | 结算 preview 返回优惠明细；下单 reserve + 写 `promotion_snapshot`；阶梯价改 SKU 成交基价（member/coupon 之前）；整船优惠在券之后按占比分摊 `promo_price`；支付成功 confirm；取消 release | 同类取最优、跨类固定顺序（阶梯价→会员→券→整船优惠）；订单历史金额不随活动变化 |
| P4 | 常购与再购 | `GET /order/app/frequent-purchase`（按用户近 90 天订单统计 SKU 频次）；`GET /order/app/orderinfo/{id}/reorder-preview`（明细 + 当前价格/库存/可购校验） | 再购必须重新确认船舶/靠港/库存/价格，不直接下单 |
| P5 | 靠港日历 + 港口看板 | `GET /vessel/admin/calls/calendar?start&end`；`GET /order/admin/delivery/port-board?portCode&date`（订单/波次/任务聚合） | 看板按港口与时间窗排序 |
| P6 | Web 页面 | 营销中心（活动列表/创建/发布暂停）、靠港日历、港口配送看板 | v-access 权限沿用 2110 ID 族新段 |
| P7 | 小程序 | 订单详情/列表“再来一单”入口（进再购预览）、结算页优惠明细展示 | 不在列表页硬算价格 |
| P8 | 收口 | 菜单 SQL、全量重建校验、双模式一致性、需求记录 | |

## 不做（阶段 3+）

AI RFQ 解析、多币种对账、ShipServ/MarineOnline 适配器、船期外部接口与 ETA 自动提醒、供应商入驻/账期发票、库存预测。这些须独立立项并通过独立 API/事件接入。

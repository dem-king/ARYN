为什么推荐 A

船供业务的视觉母题是「航次」而不是「促销」。A 把日期做成船期牌、把优惠做成登船口，放在首页不像一张普通 banner，也不会和顶部整船主视觉抢。

落地拆解

  • 入口条：新增一个装修器组件「档期入口条」，配置日期、主标题、副标题、按钮文案、跳转。
  • 会场首屏：做成微页面，四个站点分别跳「整船满减 / 商品列表 / 档期特供 / 商品列表」。
  • 数据口径：整船满减四档 1万-400 / 3万-1200 / 5万-2000 / 10万-4000，封顶4000；满额赠礼 3千-2份 / 1万-6份 / 3万-12份。

三种入口条怎么选

  • A 航次牌：首页主推，深色，适合大促档期。
  • B 港口告示：内容化首页，轻量，适合日常档期。
  • C 舱单：B2B 船代/大副视角，信息密度最高。

文案口径

「整船满减」四档、1万起；「多件囤货」船供20/50件，按件计价，不写「整箱」；「满额赠礼」写「3千2份 / 1万6份 / 3万12份」。

色板

深海军蓝做底，信号橙只给日期、按钮和编号；米白纸色负责分隔。红色只用于「档期」印章，不超过一处。

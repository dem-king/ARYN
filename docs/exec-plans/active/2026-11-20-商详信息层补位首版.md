# 商详信息层补位首版实施计划

**目标** 买家在评价前看到可核实的商品参数和履约信息，通过顶部「详情」标签查看图文。

**实现** 商品详情查询关联同租户品牌和类目。沿用 SKU 度量字段，给银鹭样板回填已知品牌和 450 mL 规格。小程序新增原生卡片，统一测量滚动锚点，管理端同步商详画布示意。

**技术** MyBatis、MySQL、UniApp、Vue 3、TypeScript。

**进度** 代码实现和隔离验证已完成。[实施记录](../../50-需求文档/2026-11-20-商详信息层补位/首版实施记录.md)

2. 在 `aryn-mall-java/db/boot`、`aryn-mall-java/db/cloud` 添加同名种子增量，仅补目标商品空值。重建并校验 Boot 全量 SQL，在隔离 MySQL 中验证两套脚本和重复执行。
3. 在 `aryn-mall-uniapp/src/sub-pages/product/goods-detail` 接入参数，补中英文词条和数据测试。履约展示复用现有配送字段，保障条按适用条件显示。
4. 同步 `aryn-mall-ui/apps/web-ele/src/views/promotion/page-designer/components/canvas-page-shell.vue` 的原生区示意。运行 Boot 编译、相关 Mapper 测试、UniApp 类型和单测、双模式 URL 与画布契约验证，记录样板资料和运行态验证结果。

**Goal:** 在 aryn-promotion 模块中实现完整的拼团（Group Buy）功能，包括拼团活动管理、开团/参团、拼团超时处理、与订单支付联动。

**Architecture:** 拼团归属于现有 aryn-promotion 模块，遵循 api(L3)/biz(L4) 分层。api 模块定义 Entity/Enum/DTO/VO/RemoteService，biz 模块实现 Controller/Service/Mapper/Job/Handler。跨模块与 order 通信通过 RocketMQ 消息（支付成功/退款事件），与 product 通信通过 Dubbo RPC（查询 SKU 信息）。

**Tech Stack:** Spring Boot 3 + MyBatis-Plus + Redisson（分布式锁）+ RocketMQ + XXL-JOB + Sa-Token

## 拼团业务模型

### 核心概念
- **拼团活动** (GroupBuyActivity): 商家配置的拼团规则，指定商品、拼团人数、拼团价、有效期
- **拼团记录** (GroupBuyRecord): 一次具体的拼团实例（开团后生成），包含当前参与人数、状态、过期时间
- **拼团参与者** (GroupBuyMember): 参与某次拼团的用户记录，关联订单号

### 状态流转
```
拼团活动: 草稿(0) → 进行中(1) → 已结束(2)
拼团记录: 拼团中(0) → 拼团成功(1) / 拼团失败(2,超时未满)
参与者: 待付款(0) → 已付款(1) → 已取消(2)
```

### 业务规则
1. 拼团价 < 原价，活动期间商品以拼团价售卖
2. 团长开团时自动成为第一个参团者
3. 拼团人数满额时自动标记拼团成功
4. 拼团超时（XXL-JOB 定时扫描）未满额则拼团失败，触发退款
5. 参团者支付成功后更新为"已付款"状态
6. 同一用户同一团只可参与一次
7. 拼团活动可指定虚拟成团人数（用于展示"已X人参团"）

**Step 2: Record Service（核心业务）**

```java
public interface IGroupBuyRecordService extends IService<GroupBuyRecord> {
	GroupBuyRecord openGroup(String activityId, String userId);
	GroupBuyRecord joinGroup(String recordId, String userId);
	IPage<GroupBuyRecordVO> getPageByActivityId(Page page, String activityId, String userId);
	void handlePaySuccess(String orderId);
	void handleGroupExpire();
}
```

ServiceImpl 要点：
- `openGroup`:
  1. 校验活动状态=进行中、活动未过期
  2. 限购校验（limitNum > 0 时查已参与次数）
  3. Redisson 分布式锁防并发（key: group_buy:activity:{activityId}）
  4. 创建 GroupBuyRecord（groupStatus=0, currentNum=1, expireAt=now+groupExpireHours）
  5. 创建 GroupBuyMember（isLeader=1, memberStatus=0）
  6. 返回 record（供前端创建订单）
- `joinGroup`:
  1. 校验 record 存在且 groupStatus=0 且未过期
  2. 校验用户未重复参团（uk_record_user）
  3. 限购校验
  4. Redisson 分布式锁
  5. 创建 GroupBuyMember（isLeader=0, memberStatus=0）
  6. currentNum + 1
  7. 若 currentNum == groupNum → 标记 groupStatus=1, successAt=now
  8. 返回 record
- `handlePaySuccess`:
  1. 根据 orderId 查 GroupBuyMember → 更新 memberStatus=1
  2. 若 record 的 currentNum == groupNum 且所有 member 都已付款 → groupStatus=1
- `handleGroupExpire`:
  1. 查询所有 groupStatus=0 AND expireAt < NOW() 的 record
  2. 标记 groupStatus=2（拼团失败）
  3. 标记所有 memberStatus=0 的 member 为 memberStatus=2
  4. 发 RocketMQ 退款消息（由 order 模块处理）

# 术语表

| 术语 | 本项目含义 | 典型代码/表 |
|---|---|---|
| 单体模式 / Boot | `aryn-boot` 聚合所有 biz，统一走 `/boot` | `ArynBootApplication` |
| 微服务模式 / Cloud | Gateway + Nacos + 独立 biz 服务，跨域用 Dubbo | `aryn-gateway`、各 `Aryn*Application` |
| ToB | 平台/商家管理端认证与运营接口 | `TobTokenController`、`aryn-mall-ui` |
| ToC | 消费者商城认证与 app 接口 | `TocTokenController`、`aryn-mall-uniapp` |
| 租户 | 一个 SaaS 商家组织；数据通过 `tenant_id` 隔离 | `sys_tenant`、`ArynTenantLineHandler` |
| 平台租户 | 可切换目标租户的管理员租户 | `PLATFORM_TENANT_ID` |
| SPU | 标准商品，如某型号手机 | `goods_spu` |
| SKU | 可售库存单元，如颜色/容量组合 | `goods_sku` |
| 页面装修 | 管理端配置、C 端渲染的页面组件 JSON | `page_design` |
| 拼团 | 活动、成团记录、参与成员 | `group_buy_activity/record/member` |
| 分销 | 分销员、佣金订单、流水和提现 | `distribution_*` |
| 商城自配送 | 商家自有配送员履约，出车单聚合配送任务，配送员用 UniApp 工作台操作 | `delivery_staff/trip/task` |
| 配送资格 | 商城账号绑定员工账号后，由认证服务结合 UPMS 配送角色判定的配送工作台准入状态（ACTIVE/UNBOUND/PERMISSION_MISSING/ACCOUNT_DISABLED/STAFF_INVALID） | `delivery_account_binding`、`DeliveryAuthService` |
| 资格操作 outbox | 配送角色的授予/回收先落表、提交后异步执行，失败按指数退避补偿，保证与本地事务最终一致 | `delivery_qualification_operation`、`DeliveryQualificationRetryJob` |
| 船舶 / 船供 | 面向船舶场景的独立业务域：船舶档案、成员与绑定审核、邀请码、靠港与港口车辆 | `vessel_info/vessel_member`、`aryn-vessel`（6700） |
| 会员等级 | 按累计积分（`total_point`）升级的等级与权益（折扣/积分倍率/免邮/专属券） | `member_level*`、`member_benefit*` |
| 会员价 | `promotion_activity` type=10 的会员等级专享价，默认可叠券/积分 | `StackActivityTypeEnum.MEMBER_PRICE` |
| 会员专区 / 低价捡漏 | 首页装修多 Tab 商品流的两种数据源语义：会员价活动货盘 / 折扣力度优先排序，不建新表 | `AppMemberActivityGoodsController`、`retail-query.ts` |
| 积分 | 下单抵现（基数不含运费，默认单笔上限 20%）+ 兑券 + 签到/注册/订单完成发放，`biz_no` 幂等 | `points_config/record`、`AppPointsController` |
| 单点登录 | 同一账号全局只保留一个会话：Sa-Token `is-concurrent: false`，TOB 新登录顶掉旧登录 | `SingleSessionPolicyContractTest` |
| 逻辑删除 | 用 `del_flag` 标记，不执行物理删除 | `0` 正常，`1` 删除 |
| API 模块 | 跨服务接口、DTO、Entity 定义 | `aryn-*-api` |
| Biz 模块 | Controller、Service、Mapper 和 RPC 实现 | `aryn-*-biz` |
| 动态菜单 | 后端按权限下发的管理端路由元数据 | `/upms/menu`、`sys_menu` |
| satoken | 前后端传递 Sa-Token 的请求头名称 | `satoken` header |

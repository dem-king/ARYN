# 术语表

| 术语 | 本项目含义 | 典型代码/表 |
|---|---|---|
| 单体模式 / Boot | `aryn-boot` 聚合所有 biz，统一走 `/boot` | `ArynBootApplication` |
| 微服务模式 / Cloud | Gateway + Nacos + 独立 biz 服务，跨域用 Dubbo | `aryn-gateway`、各 `Aryn*Application` |
| ToB | 平台/商家管理端认证与运营接口 | `TobTokenController`、`aryn-mall-ui` |
| ToC | 消费者商城认证与 app 接口 | `TocTokenController`、`aryn-mall-uniapp` |
| 租户 | 一个 SaaS 商家组织；数据通过 `tenant_id` 隔离 | `sys_tenant`、`ArynTenantLineHandler` |
| 平台租户 | 可切换目标租户的管理员租户 | `PLATFORM_TENANT_ID` |
| SPU | 标准商品，如某型号手机 | `goods_spu` |
| SKU | 可售库存单元，如颜色/容量组合 | `goods_sku` |
| 页面装修 | 管理端配置、C 端渲染的页面组件 JSON | `page_design` |
| 拼团 | 活动、成团记录、参与成员 | `group_buy_activity/record/member` |
| 分销 | 分销员、佣金订单、流水和提现 | `distribution_*` |
| 逻辑删除 | 用 `del_flag` 标记，不执行物理删除 | `0` 正常，`1` 删除 |
| API 模块 | 跨服务接口、DTO、Entity 定义 | `aryn-*-api` |
| Biz 模块 | Controller、Service、Mapper 和 RPC 实现 | `aryn-*-biz` |
| 动态菜单 | 后端按权限下发的管理端路由元数据 | `/upms/menu`、`sys_menu` |
| satoken | 前后端传递 Sa-Token 的请求头名称 | `satoken` header |

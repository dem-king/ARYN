# 环境与启动

## 推荐运行时

| 组件 | 项目要求 | 当前分析机 | 结论 |
|---|---|---|---|
| JDK | 17 | 17.0.9 | 满足 |
| Maven | 3.6+ | 3.9.9 | 满足 |
| Node.js | UI `>=20.10`；UniApp `>=22` | 20.15.1 | UI 满足，UniApp 不满足 |
| pnpm | UI 锁定 10.10.0；UniApp 锁定 9.9.0 | 9.12.3 | 建议用 Corepack 按子项目切换 |
| MySQL | 8.x | 未验证 | 运行前确认 |
| Redis | 6.x+ | 未验证 | 运行前确认 |

微服务模式还需要 Nacos、RocketMQ；涉及分布式事务时需要 Seata；定时任务需要 XXL-JOB Admin。

## 数据库初始化

单体模式使用 `aryn-mall-java/db/boot/`，微服务模式使用 `aryn-mall-java/db/cloud/`。导入前先审阅 SQL 中的默认账号、密码和 Nacos 配置，不要直接用于生产。

## 后端单体模式

```powershell
cd aryn-mall-java
mvn clean compile -pl aryn-boot -am
mvn test -pl aryn-boot -am
mvn spring-boot:run -pl aryn-boot
```

- 默认端口：`9999`
- Context path：`/boot`
- OpenAPI：`http://localhost:9999/boot/v3/api-docs`
- Knife4j：`http://localhost:9999/boot/doc.html`

启动前修改 `aryn-boot/src/main/resources/application-dev.yml`，优先通过环境变量或本地不提交配置注入数据库、Redis、RocketMQ、短信和任务调度凭证。

## 后端微服务模式

入口端口为 Gateway `9999`。源码配置中的主要服务端口：auth `5227`、upms `5327`、product `6300`、order `6400`、promotion `6500`、pay `6900`、generator `7003`、monitor `7001`、user `7527`。

各服务从 Nacos 读取 `application-<profile>.yml` 和 `<service>-<profile>.yml`。先启动基础设施，再按认证/权限、业务服务、Gateway 的顺序启动。

## 管理后台

```powershell
cd aryn-mall-ui
corepack enable
pnpm install
pnpm dev:ele
```

- 开发端口：`5777`
- 开发 API 前缀：`/api`，由 Vite 代理或部署网关处理。
- `VITE_OPEN_BOOT=true` 时，请求从 `/domain/path` 改写为 `/boot/path`。

最小验证：

```powershell
pnpm check:type
pnpm lint
pnpm test:unit
pnpm build:ele
```

## UniApp

先切换到 Node 22，再执行：

```powershell
cd aryn-mall-uniapp
corepack enable
pnpm install
pnpm dev:mp-weixin
```

常用替代目标为 `pnpm dev:h5`、`pnpm build:mp-weixin`、`pnpm build:h5`。最小静态验证是 `pnpm type-check`；当前 `package.json` 没有 `lint` 脚本，也未发现测试文件。

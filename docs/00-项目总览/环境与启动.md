## 2. 数据库初始化

### 单体模式

```bash
cd aryn-mall-java

# 导入 schema
mysql -u root -p < db/boot/1schema.sql

# 导入业务数据
mysql -u root -p < db/boot/2aryn_boot.sql
```

### 微服务模式

```bash
cd aryn-mall-java

# 导入 db/cloud/ 下的 SQL 文件
# 各服务独立数据库：aryn_upms, aryn_user, aryn_order, aryn_pay, aryn_product, aryn_promotion
```

## 4. 启动命令

### 后端

```bash
cd aryn-mall-java

# 编译
mvn clean compile -pl aryn-boot -am

# 运行 (IDEA 直接运行 ArynBootApplication.java)
# 单体模式启动端口: 9999
# 接口文档: http://localhost:9999/boot/doc.html
```

### 管理后台

```bash
cd aryn-mall-ui

pnpm install        # 安装依赖 (首次)
pnpm dev            # 启动开发服务器
```

### 移动端

```bash
cd aryn-mall-uniapp

pnpm install        # 安装依赖
pnpm dev:mp-weixin  # 启动微信小程序开发
pnpm dev:h5         # 启动 H5 开发
```

## 6. 常见问题

### Q: 单体与微服务如何切换？

单体使用 `aryn-boot` 聚合模块；拆分为微服务后排除 `aryn-boot`，各 biz 独立部署。

### Q: 跨模块调用怎么做？

单体直接注入 Service；微服务通过 Dubbo `@DubboReference` 调用 Remote Service（定义在 `*-api` 中）。

### Q: 多租户如何实现？

`aryn-common-mybatis` 中的 `ArynTenantLineHandler` 解析请求头 `TENANT-ID`，自动为 SQL 添加 `tenant_id` 过滤。

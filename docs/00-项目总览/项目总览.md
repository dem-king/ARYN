# 项目总览

## 一句话定位

悦航购（Aetheryn Mall）是面向多租户商家的电商 SaaS，覆盖后台运营、C 端商城、商品、订单、支付、会员和营销，并支持单体与微服务两种后端部署形态。

## 代码区

| 目录 | 角色 | 关键技术 | 主要入口 |
|---|---|---|---|
| `aryn-mall-java/` | 商城后端 | Java 17、Spring Boot 3.5.8、Spring Cloud 2025.0.0、Dubbo 3.3.6、MyBatis-Plus | `ArynBootApplication` 或各服务 `*Application` |
| `aryn-mall-ui/` | 商家/平台管理后台 | Vue 3.5、Vite 6、TypeScript、Element Plus、Turbo、pnpm workspace | `apps/web-ele/src/main.ts` |
| `aryn-mall-uniapp/` | C 端商城 | UniApp、Vue 3、TypeScript、Alova、Pinia、Wot Design Uni | `src/main.ts`、`src/pages.json` |
| `xxl-job-3.2.0/` | 上游调度平台源码副本 | Java 17、Spring Boot 3.5.4、XXL-JOB 3.2.0 | `xxl-job-admin`；不在商城后端聚合 POM 中 |

## 部署形态

```text
管理后台 / UniApp
        |
        +-- 单体：:9999/boot -> aryn-boot -> 全部 biz 模块（Dubbo injvm）
        |
        +-- 微服务：:9999 -> aryn-gateway -> auth/upms/user/order/pay/product/promotion
                                      |-> Nacos 注册配置 + Dubbo RPC

共享基础设施：MySQL、Redis、RocketMQ、XXL-JOB；微服务模式另需 Nacos，分布式事务可用 Seata。
```

## 后端业务域

| 业务域 | API/Biz 模块 | 主要能力 |
|---|---|---|
| 权限与租户 | `aryn-upms-api/biz` | RBAC、菜单、字典、租户、素材、存储配置 |
| C 端用户 | `aryn-user-api/biz` | 用户、地址、会员、积分、余额、充值、签到、标签 |
| 商品 | `aryn-product-api/biz` | SPU/SKU、分类、规格、评价、收藏、足迹 |
| 订单 | `aryn-order-api/biz` | 购物车、结算、订单、配送、退款、统计 |
| 支付 | `aryn-pay-api/biz` | 支付配置、交易单、通知、退款 |
| 营销 | `aryn-promotion-api/biz` | 优惠券、分销、拼团、页面装修 |
| 认证与入口 | `aryn-auth`、`aryn-gateway`、`aryn-boot` | 前后台登录、网关、单体聚合 |

## 当前覆盖与边界

- SQL 共 17 个文件，静态提取到 89 个唯一表名，包含业务库、Nacos、代码生成和 XXL-JOB 表。
- 后端发现 11 个启动类和 77 个商城 Controller；管理端有 66 个 API 文件、157 个业务视图；UniApp 有 35 个 API 文件、85 个 Vue 文件。
- `target/` 等构建产物在本地存在但已由 Git 忽略，不能作为源码事实的唯一依据。
- 当前工作区有首页装修、登录页和品牌资源等未提交用户修改；后续 Agent 不得回退或覆盖。

## 最高关注风险

1. 存量库执行租户登录标识唯一索引迁移前，必须先处理重复用户名、手机号和 `app_id`。
2. 开发配置和数据库种子包含明文敏感值。
3. 移动端与部分后端业务域缺少自动化测试。
4. 当前 Node 20.15.1 不满足 UniApp 声明的 Node `>=22`，也低于管理端锁定工具链的推荐版本。
5. 历史 Harness 脚本在当前工作树处于删除状态，不能把相关命令当作现成可用验证。

# 项目总览

> 详细架构信息参见 [ARCHITECTURE.md](../ARCHITECTURE.md)。

## 1. 系统定位

悦航购（Aetheryn Mall）是一套面向中小型电商的 **SaaS 商城系统**，支持 **单体模式（Boot）** 与 **微服务模式（Cloud）** 双形态运行。

| 属性 | 值 |
|------|-----|
| Base Package | `com.aryn.cloud` |
| 版本 | 3.2.1 |
| JDK | 17 |
| 许可 | 商业软件 |

## 2. 子项目概览

| 目录 | 技术栈 | 定位 | 说明 |
|------|--------|------|------|
| `aryn-mall-java/` | Spring Boot 3 + Spring Cloud Alibaba + Dubbo | 后端服务 | 6 个业务模块 + 13 个公共模块 |
| `aryn-mall-ui/` | Vue 3.5 + Vite 6 + TypeScript 5.8 + Element Plus 2.9 | 管理后台 | 基于 Vben Admin 3.2.1 二次开发 |
| `aryn-mall-uniapp/` | UniApp + Vue 3 + TypeScript + Alova 3.x | C 端移动商城 | 支持微信小程序 / H5 / App |

三个子项目通过 RESTful API 通信，前端通过网关（单体模式下直接访问 `aryn-boot`）调用后端服务。

## 3. 部署架构

```
用户请求 → Nginx
              ├→ aryn-mall-ui (Vue 3 SPA)           # 管理后台
              ├→ aryn-mall-uniapp (UniApp)           # C端商城
              └→ aryn-gateway :9999                  # API 网关
                   ├→ aryn-auth :5227               # 认证中心
                   ├→ aryn-upms-biz                 # 权限管理 (RPC)
                   ├→ aryn-user-biz                 # 用户服务 (RPC)
                   ├→ aryn-order-biz                # 订单服务 (RPC)
                   ├→ aryn-pay-biz                  # 支付服务 (RPC)
                   ├→ aryn-product-biz              # 商品服务 (RPC)
                   └→ aryn-promotion-biz            # 营销服务 (RPC)

中间件层:
  Nacos (注册/配置) | MySQL 8.x | Redis | RocketMQ | Sentinel | Seata
```

### 单体模式 vs 微服务模式

| 维度 | 单体模式 (Boot) | 微服务模式 (Cloud) |
|------|-----------------|-------------------|
| 启动入口 | `aryn-boot` 聚合模块 | 各 `*-biz` 独立部署 |
| 模块通信 | Spring DI 直接注入 | Dubbo Triple 协议 RPC |
| 配置中心 | application-dev.yml | Nacos |
| 服务注册 | 无 | Nacos |
| 适用场景 | 快速部署、开发调试 | 生产环境、独立扩缩容 |

## 5. 核心设计决策

| 决策 | 说明 |
|------|------|
| 单体/微服务双模式 | `aryn-boot` 聚合所有 biz 模块用于快速部署；拆分后各 biz 通过 Dubbo RPC 通信 |
| 多租户隔离 | 所有表含 `tenant_id`，通过 MyBatis 拦截器自动注入 |
| API 与 Biz 分离 | 每个业务模块分为 `*-api`（接口+DTO）和 `*-biz`（实现），支持 Dubbo 远程调用 |
| SaaS 权限模型 | Sa-Token + RBAC，管理端与 C 端分离认证 |
| 事件驱动 | RocketMQ（跨服务异步）+ Spring Event（服务内异步） |

## 2026-07-16 多租户隔离加固

### 需求

在开发阶段完整补齐单体与微服务多租户隔离，并建立防止后续 schema、配置和拦截绕过漂移的硬门禁。

### 影响范围

- Boot 61 张租户表全集与 user/upms/product/promotion/pay/order Nacos 子集。
- 公共 MyBatis 租户处理器、JDBC schema 启动校验和 H2 回归测试。
- Boot/Cloud 基础 SQL、登录前全局定位唯一索引及存量库迁移脚本。
- Nacos 内容 MD5、配置一致性测试和 `@InterceptorIgnore` 审计。

### 结果

会员、积分、余额、标签、分销和拼团表已纳入租户隔离，4 个无 `tenant_id` 的旧表名已移除。应用会在 schema 与白名单不一致或白名单为空时拒绝启动，白名单变更必须重启；生成器显式关闭校验。存量库执行有效记录函数唯一索引迁移前必须先人工处理重复用户名、手机号或 `app_id`。

### 验证

- `mvn -q compile -pl aryn-boot -am` 通过。
- `aryn-common-mybatis` 12 个租户测试通过，`aryn-boot` 9 个配置一致性和绕过审计测试通过。
- 完整 `mvn test -pl aryn-boot -am` 仍在既有 `aryn-user-biz` 测试编译阶段失败：测试使用的 Mockito 调用与当前 MyBatis-Plus 批量重载存在歧义，并直接访问了受保护的 `baseMapper`。
- 本机无 MySQL 客户端和 Docker，MySQL 8.0 函数索引迁移尚未做真实数据库执行验证。

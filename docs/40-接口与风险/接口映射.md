# 接口映射

> 前后端 API 完整映射表，按业务域组织。

## 1. API 路由约定

| 前缀 | 说明 | 认证要求 |
|------|------|----------|
| `/admin/{domain}/**` | 管理端接口 | `@SaCheckPermission` |
| `/app/{domain}/**` | 应用端接口 | `@SaCheckLogin` |
| `/auth/**` | 认证接口 | 无需登录 |
| `/pay/callback/**` | 支付回调 | 无需登录（验签） |

# 接口映射

## 路径规则

| 模式 | 前端源码路径 | 实际请求示例 | 后端入口 |
|---|---|---|---|
| 微服务 | `/product/goodsspu/page` | `/product/goodsspu/page` | Gateway 转发到 product，Controller `/goodsspu` |
| 单体 | `/product/goodsspu/page` | `/boot/goodsspu/page` | Boot context `/boot` + Controller `/goodsspu` |

管理端和 UniApp 都会在 `VITE_OPEN_BOOT=true` 时去掉第一个业务域段。排查 404 时先确认运行模式与最终 URL。

## 会员接口与订单契约

| 动作 | 路径/接口 | 约束 |
|---|---|---|
| 当前会员权益 | `GET /mall-user/app/member/benefits` | 只读取 token 当前用户和启用等级；返回最优折扣、积分倍率、免邮及专属券模板集合 |
| 可见等级与权益 | `GET /mall-user/app/member/levels`、`GET /mall-user/app/member/level-benefits` | C 端不返回禁用等级或禁用权益 |
| 会员资料/密码 | `/mall-user/app/userinfo/**` | 资料更新强制使用 token 用户 ID；密码修改校验当前密码和两次新密码，统一使用 BCrypt |
| 订单计价 | 用户域 `RemoteMallUserService.getMemberBenefits` | 先应用会员折扣，再校验和分摊当前用户优惠券；免邮最后将运费清零 |
| 订单完成成长 | `OrderCompleteEvent` -> 用户域监听器 | 事件携带实付商品金额及下单时固化的积分倍率，按订单唯一键幂等处理 |
| 等级专属券 | 营销域 `RemoteCouponUserService` | `benefitValue` 作为券模板 ID，首次进入等级按“等级 ID:权益 ID”来源幂等发券 |

## 页面装修接口

| 动作 | 管理端路径 | 权限 | 公开端路径/约束 |
|---|---|---|---|
| 编辑详情/保存草稿 | `GET /pagedesign/{id}/editor`、`PUT /pagedesign/{id}/draft` | `promotion:pagedesign:edit` | 草稿不公开，保存携带 `draftRevision` |
| 预览 | `POST /pagedesign/{id}/preview-token` | `promotion:pagedesign:edit` | `GET /app/pagedesign/preview/{token}`，令牌绑定租户/页面/修订号并有 TTL |
| 发布/下线 | `POST /pagedesign/{id}/publish|unpublish` | `promotion:pagedesign:publish` | App 只读取当前发布版本 |
| 历史/回滚 | `GET /pagedesign/{id}/versions`、`POST /pagedesign/{id}/versions/{versionId}/rollback` | 查询用 `get`，回滚用 `promotion:pagedesign:rollback` | 回滚生成新快照 |
| 模板 | `/pagedesign/templates` | 查询用 `get`，写操作用 `promotion:pagedesign:template` | 无公开写入口 |
| 首页/微页面 | 管理端按页面 ID 编辑 | 原有查看/编辑权限 | `GET /app/pagedesign`、`GET /app/pagedesign/{id}` 只返回发布快照 |

Boot/Cloud 菜单种子均包含 `publish/rollback/template` 权限。所有管理端 PageDesign 端点必须显式声明 `@SaCheckPermission`；App 发布读取与短期预览保持公开，但仍由租户上下文隔离。

装修公开读取的匿名白名单同时覆盖 `/upms/app/tenant/shop-info`、`/product/app/**`、`/promotion/app/pagedesign/**`、`/promotion/app/groupbuy/activity/**` 和 `/promotion/app/groupbuy/record/page`。Cloud 白名单存于 `db/cloud/3aryn_nacos.sql`，Boot 白名单存于 `aryn-boot/src/main/resources/application.yml`，新增公开读取接口时必须保持两处一致。

## 认证与公共头

| 请求头 | 管理端 | UniApp | 后端用途 |
|---|---|---|---|
| `satoken` | access store | authStore | Sa-Token 登录态 |
| `tenant-id` | 平台切租户时可设置 | 从 `VITE_TENANT_ID` 设置 | TenantContext/MyBatis 隔离 |
| `Accept-Language` | 设置 | 未统一发现 | 管理端国际化 |
| `platform-type` | 无 | H5/APP/WX_MA | ToC 平台登录和业务判断 |
| `app-id` | 无 | 微信小程序设置 | 小程序账号与支付配置 |

## 联调验证清单

1. 记录源码 URL、浏览器最终 URL、运行模式和 Gateway/Boot context。
2. 验证 token 类型、租户 ID 与平台头，不仅看 HTTP 200。
3. 验证业务响应 `code === 0` 和真实 data schema。
4. 写接口检查事务、幂等、逻辑删除和租户条件。
5. 动态菜单接口同时验证权限码、component 路径与租户套餐授权。

## 当前重要结论

1. 根目录包含商城后端、管理后台、UniApp 商城和一份独立 XXL-JOB 3.2.0 源码；XXL-JOB 不属于 `aryn-mall-java` 根 POM 模块。
2. 后端支持 `/boot` 单体模式和 Gateway + Nacos + Dubbo 微服务模式；管理端和移动端用 `VITE_OPEN_BOOT` 切换路径。
3. 管理端业务菜单主要由 `/upms/menu` 动态下发，静态路由模块只有 dashboard，排查“页面有文件但菜单不可见”时必须同时检查数据库菜单。
4. 多租户启动校验、SQL/配置一致性测试和拦截绕过审计已经建立，但新配送表再次造成 Boot/Cloud 白名单漂移；修复前不能声明租户隔离完整。存量库执行唯一索引迁移前仍需先处理重复全局标识。
5. 开发配置和 SQL 种子中存在明文敏感配置；生产环境 API 地址仍有 localhost/模板值，部署前必须外置并核对。
6. 2026-08-31 静态盘点发现后端 92 个测试类、管理端 62 个测试文件、UniApp 9 个测试文件；数量不等于关键交易链路已被覆盖，本轮也未执行全量测试。
7. 配送履约、秒杀和折扣活动已进入三端源码，但配送实现与 2026-07-28 设计存在偏差；Cloud 租户表配置、UniApp Cloud 路径和专项测试仍需优先核对。

> 证据：`aryn-mall-java/pom.xml`、三端 `package.json`、`db/boot`、`db/cloud`、Controller/API/测试文件静态盘点及 `git log`；检查于 2026-08-31；置信度：已验证（结构与文件事实），运行态未知。
